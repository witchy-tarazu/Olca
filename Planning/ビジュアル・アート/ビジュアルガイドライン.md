# ビジュアルガイドライン - Olca

## プロジェクト概要

本ドキュメントは、カードアクションRPG「Olca」のビジュアル全体に関する指針を定めるものです。
開発者・アーティストは本ガイドラインに従い、一貫性のあるビジュアル表現を実現してください。

---

## ビジュアルコンセプト

### コアコンセプト
「ドット絵の温かみ」と「モダンなフラットUI」の融合

- **ノスタルジックな世界観**: ドット絵によるレトロな雰囲気
- **洗練された操作性**: フラットデザインによる視認性と直感性
- **感情表現の豊かさ**: ADVパートでは通常イラストによる繊細な演出

### ターゲット解像度
- **基本解像度**: 1920x1080 (Full HD)
- **アスペクト比**: 16:9
- **UIセーフエリア**: 画面端から5%のマージンを確保

---

## アートスタイルの使い分け

本プロジェクトでは、場面に応じて3つのアートスタイルを使い分けます。

### 1. ドットアート（主要スタイル）

**使用箇所:**
- ダンジョン探索画面
- バトル画面のキャラクター
- ゲームフィールド全般
- 一部のエフェクト

**特徴:**
- ピクセルパーフェクト
- レトロゲーム風の温かみ
- アニメーションの明確なフレーム感

**詳細:** [ドットアート仕様.md](ドットアート仕様.md) を参照

### 2. 通常イラスト（高精細スタイル）

**使用箇所:**
- ADVパートの立ち絵
- スチルイラスト（イベントシーン）
- 一部の派手なバトルエフェクト
- カードイラスト（検討中）

**特徴:**
- アニメ調の塗り
- 繊細な表情表現
- 高解像度（最低でも1024px以上の縦幅）

**詳細:** [ADVパート仕様.md](ADVパート仕様.md) を参照

### 3. フラットデザインUI

**使用箇所:**
- すべてのゲームUI
- ボタン・ウィンドウ
- アイコン類
- テキスト表示

**特徴:**
- シンプルで視認性が高い
- 影や装飾を最小限に
- ベクター的な表現

**詳細:** [UIデザイン仕様.md](UIデザイン仕様.md) を参照

## 色彩設計

### メインカラーパレット

プロジェクト全体で統一感を持たせるため、以下のカラーパレットを基準とします。

```
ダークブルー: #2C3E50  // メインUI背景
ミディアムブルー: #3498DB  // アクセント、選択状態
ライトブルー: #5DADE2  // ホバー、補助色
```

#### セカンダリカラー
```

ミディアムグレー: #7F8C8D  // 非アクティブ要素
ライトグレー: #BDC3C7  // 背景、区切り線
```

```
レッド: #E74C3C    // 警告、HP減少
```

ドットアートでは、上記カラーに加えて以下の制限を設けます:

詳細は [ドットアート仕様.md](ドットアート仕様.md) を参照してください。

## 画面構成の基本原則

### レイヤー構造

画面は以下の優先度でレイヤーを重ねます（下から順）:

1. **背景レイヤー**: ダンジョン、バトル背景
2. **ゲームオブジェクトレイヤー**: キャラクター、敵、オブジェクト
3. **エフェクトレイヤー**: 攻撃エフェクト、パーティクル
4. **UIベースレイヤー**: ゲームUI（HP、ゲージ等）
5. **UI最前面レイヤー**: モーダルウィンドウ、ポップアップ
6. **システムレイヤー**: ポーズメニュー、設定画面

### グリッドシステム

UI配置は8pxグリッドを基準とします:

- **余白**: 8px, 16px, 24px, 32px
- **要素間隔**: 8pxの倍数
- **ボタンサイズ**: 最小48px（タッチ操作考慮）

## タイポグラフィ

### フォント選定

#### 日本語フォント
- **メインフォント**: Noto Sans JP（視認性重視）
- **タイトル・見出し**: Noto Sans JP Bold
- **フレーバーテキスト**: 源ノ角ゴシック Regular

#### 英数字フォント
- **UI数値**: Roboto Condensed（コンパクト表示）
- **タイトルロゴ**: Press Start 2P（ドット風フォント）

### フォントサイズ

```
特大見出し: 48px  // タイトル画面
大見出し: 32px    // 章タイトル
中見出し: 24px    // セクション見出し
本文: 18px        // 通常テキスト
小文字: 14px      // 補足情報
極小文字: 12px    // フッター、注釈
```

### 行間・字間
- **行間**: フォントサイズの1.5倍
- **字間**: 0px（デフォルト）、見出しのみ2-4px

## アニメーション原則

### 基本方針
- **快適な操作感**: UIアニメーションは100-200ms以内
- **ゲーム演出**: バトルエフェクトは300-800ms
- **明確なフィードバック**: 操作に対する即座の視覚反応

### イージング
- **UI表示**: Ease Out（素早く表示、ゆっくり停止）
- **UI非表示**: Ease In（ゆっくり開始、素早く消失）
- **強調**: Ease In Out Elastic（バウンド効果）

### フレームレート
- **ドットアニメーション**: 8-12fps（レトロ感重視）
- **UIアニメーション**: 60fps（滑らか）
- **エフェクト**: 30-60fps（種類による）

詳細は各仕様書を参照:
- [キャラクターアニメーション仕様.md](キャラクターアニメーション仕様.md)
- [バトルエフェクト仕様.md](バトルエフェクト仕様.md)

## パフォーマンス指針

### テクスチャサイズ
- **ドットスプライト**: 16x16 ~ 128x128px
- **立ち絵**: 1024x2048px以下
- **背景**: 2048x2048px以下
- **UI要素**: 512x512px以下

### アトラス化
- 同一シーンで使用するスプライトはSprite Atlasにまとめる
- UI要素は共通アトラスを作成
- Draw Call削減を意識

### メモリ使用量
- 1シーンあたりテクスチャメモリ: 200MB以下を目標
- 不要なアセットはアンロード

---

## 禁止事項

以下の表現は、本プロジェクトのビジュアルコンセプトから外れるため使用しないでください:

- ❌ 3Dモデル（2Dゲームのため）
- ❌ リアル系の写真素材
- ❌ 過度なグラデーション・グロー効果（フラットデザインに反する）
- ❌ 統一感のない外部アセット流用
- ❌ 低解像度の引き伸ばし（ドット絵以外）
