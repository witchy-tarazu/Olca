# ADVパート仕様 - Olca

## 概要

本ドキュメントは、Olcaプロジェクトにおける **アドベンチャー（ADV）パート** のビジュアル仕様を定めます。
ADVパートでは、ドット絵ではなく **通常の高精細イラスト** を使用し、物語やキャラクター表現を豊かにします。

---

## ADVパートとは

### 使用場面
- **ストーリーシーン**: 物語の進行、イベント
- **キャラクター会話**: NPCとの対話
- **チュートリアル**: ゲームシステムの説明
- **エンディング**: ゲームクリア後のシーン

### ドット絵との使い分け
```
ゲームプレイ（ダンジョン・バトル）: ドット絵
ストーリー・会話シーン: 通常イラスト
UI: フラットデザイン
```

---

## アートスタイル

### ビジュアルコンセプト
「アニメ調の柔らかい塗りと繊細な表情表現」

#### スタイルの特徴
- **アニメ塗り**: セルシェーディング、段階的な影
- **明確な線画**: 太さ2-4pxの輪郭線
- **柔らかい配色**: 彩度を抑えた落ち着いた色調
- **感情表現**: 目・表情の細かい描き分け

#### 参考スタイル
- STEINS;GATE
- 428 〜封鎖された渋谷で〜
- CLANNAD

### 禁止事項
- ❌ リアル系の厚塗り（世界観に合わない）
- ❌ SDデフォルメ（ドット絵とスタイルが混在）
- ❌ 過度な光エフェクト・グロー

## 立ち絵（キャラクターポートレート）

### 基本仕様

#### 解像度
```yaml
縦幅: 1200px（推奨）
横幅: 600-800px（キャラクターの体格により調整）
フォーマット: PNG（透過あり）
解像度: 300dpi（制作時）、72dpi（Unity用出力）
```

#### 構図
```yaml
上半身 + 一部下半身: 胸から太もも程度まで
視線: やや下向き（プレイヤーを見る角度）
ポーズ: 自然な立ち姿、キャラ性が出る仕草
余白: 上下左右に適度な余白（トリミング対応）
```

### レイヤー構成

効率的な差分管理のため、以下のレイヤー構成を推奨:

```
キャラ名_立ち絵.psd
├── [フォルダ] 装飾
│   ├── アクセサリー
│   ├── エフェクト（汗、頬染め等）
│   └── 特殊演出
├── [フォルダ] 表情
│   ├── 口_通常
│   ├── 口_笑顔
│   ├── 口_驚き
│   ├── 口_怒り
│   ├── 目_通常
│   ├── 目_笑顔
│   ├── 目_驚き
│   ├── 目_怒り
│   ├── 眉_通常
│   ├── 眉_困り
│   └── 眉_怒り
├── [フォルダ] 髪
│   ├── 前髪
│   ├── 後ろ髪
│   └── ハイライト
├── [フォルダ] 服装
│   ├── 服_ベース
│   ├── 服_影
│   └── 服_ハイライト
├── [フォルダ] 体
│   ├── 肌_ベース
│   ├── 肌_影
│   └── 肌_ハイライト
└── 線画
```

### 表情差分

各キャラクターに以下の表情を用意:

#### 必須表情（8種）
1. **通常**: デフォルト、落ち着いた表情
2. **笑顔**: 喜び、嬉しい
3. **悲しみ**: 落胆、寂しい
4. **怒り**: 不機嫌、憤慨
5. **驚き**: びっくり、ショック
6. **困り**: 戸惑い、心配
7. **照れ**: 恥ずかしい、頬を赤らめる
8. **真剣**: 集中、決意

#### オプション表情
- 泣き顔
- ドヤ顔
- 不敵な笑み
- 目を閉じる
- ウィンク

### 表情パーツ組み合わせ

表情は **目・眉・口** の組み合わせで表現:

```
笑顔 = 目_笑顔 + 眉_通常 + 口_笑顔
困り = 目_通常 + 眉_困り + 口_困り
驚き = 目_驚き + 眉_上がり + 口_驚き
```

効率化のため、パーツ単位で管理し、Unity側で組み合わせ。

### ポーズ差分

メインキャラクターには複数のポーズを用意:

```yaml
基本ポーズ: 1種（必須）
追加ポーズ: 2-3種（余裕があれば）
  - 腕組み
  - 指差し
  - 手を振る
  - 考える仕草
```

### 立ち絵の配置

ADV画面での配置例:

```
┌────────────────────────────────────┐
│     [立ち絵1]         [立ち絵2]      │
│      (左)              (右)         │
│                                    │
│ ┌──────────────────────────────┐  │
│ │ [名前]                        │  │
│ │ 台詞テキスト...                │  │
│ └──────────────────────────────┘  │
└────────────────────────────────────┘

配置位置:
  - 1人: 中央または左寄り
  - 2人: 左右に配置
  - 3人: 左・中央・右（または中央を奥に小さく）
```

## スチルイラスト（イベントCG）

### 基本仕様

#### 解像度
```yaml
サイズ: 1920x1080px（16:9）
フォーマット: PNG / JPEG
解像度: 72dpi
```

#### 用途
- 重要なストーリーシーン
- エンディングCG
- 特別なイベント（出会い、別れ等）

### 構図・演出

#### 構図パターン
- **バストアップ**: 感情表現重視
- **全身**: アクションシーン、状況説明
- **俯瞰**: 空間・環境を見せる
- **アップ**: 目や手など、特定部位の強調

#### ライティング
- **ドラマチックな光**: 逆光、サイド光で雰囲気を演出
- **色温度**: シーンの感情に合わせた配色（温かい/冷たい）

### 制作枚数の目安

```yaml
最小構成: 5-10枚（主要シーンのみ）
推奨構成: 15-20枚（各章に1-2枚）
フル構成: 30枚以上（豪華版）
```

## 背景イラスト

### 基本仕様

#### 解像度
```yaml
サイズ: 1920x1080px（16:9）
フォーマット: JPEG（透過不要）
解像度: 72dpi
```

#### 種類
- **室内**: 自宅、店、ギルド等
- **屋外**: 街、森、ダンジョン入口等
- **特殊**: 戦闘後の廃墟、幻想的な空間

### スタイル

#### パース・奥行き
- 1点透視または2点透視
- 立ち絵が映える奥行き感

#### ディテールレベル
```
前景: ディテール高（ただし立ち絵の邪魔をしない）
中景: 適度なディテール
背景: シンプルに、ぼかしも活用
```

#### 色調
- 立ち絵が目立つよう、やや彩度を抑える
- 暗すぎず、明るすぎず
- テキストウィンドウと被る下部は暗めに調整

## テキスト演出

### テキスト送り

#### 表示方法
- **1文字ずつ表示**: タイプライター風
- **クリックで全文表示**: スキップ機能
- **既読テキスト**: 高速スキップ可能

#### 効果音
- テキスト表示音: 軽い「ピッ」音（50ms間隔）
- キャラクターごとに音を変える（オプション）

### 特殊演出

#### テキストエフェクト
- **強調**: 文字を大きく、色を変える
- **震え**: 重要なシーンで文字を揺らす
- **フェード**: ゆっくり表示

#### ウィンドウアニメーション
```yaml
表示: 下からスライドイン（200ms）
非表示: 下にスライドアウト（150ms）
```

### スクリプトデータ形式

#### シナリオスクリプト（JSON or YAML）

```yaml

scenes:
  - id: scene_01
    background: room_home
    commands:
      - type: show_character
        character: alice
        position: left
        expression: normal

      - type: dialogue
        character: alice
        text: "こんにちは。元気してた？"

      - type: show_character
        character: bob
        position: right
        expression: smile

      - type: dialogue
        character: bob
        text: "ああ、元気だよ！"

      - type: choice
        options:
          - text: "一緒に冒険に行こう"
            next: scene_02a
          - text: "今は忙しいんだ"
            next: scene_02b
```

### 立ち絵の差分管理（Unity）

#### Sprite組み合わせ方式

```csharp
// CharacterPortrait.cs
public class CharacterPortrait : MonoBehaviour
{
    [SerializeField] private SpriteRenderer baseRenderer;
    [SerializeField] private SpriteRenderer faceRenderer;
    [SerializeField] private SpriteRenderer accessoryRenderer;

    private Dictionary<string, Sprite> faceSprites;

    public void SetExpression(string expressionName)
    {
        if (faceSprites.TryGetValue(expressionName, out Sprite sprite))
        {
            faceRenderer.sprite = sprite;
        }
    }
}
```

## FAQ

### Q: 立ち絵とスチルで絵柄が変わっても良いですか？
A: 統一感を保つため、同じアーティストまたは同じスタイルガイドに従うこと。

### Q: 全キャラに立ち絵が必要ですか？
A: メインキャラのみでOK。サブキャラは名前のみ、またはシンプルなアイコン表示も可。

### Q: ボイスは必須ですか？
A: オプションです。テキストのみでも問題ありません。

### Q: 立ち絵の表情差分は何枚必要ですか？
A: 最低8種類。余裕があれば15-20種類あると表現の幅が広がります。
