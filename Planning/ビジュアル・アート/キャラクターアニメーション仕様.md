# キャラクターアニメーション仕様 - Olca

## 概要

本ドキュメントは、Olcaプロジェクトにおける **Spriteアニメーション** の技術仕様を定めます。
すべてのキャラクターアニメーションは、ドット絵スプライトを用いたフレームアニメーションで実装します。

---

## アニメーション基本方針

### コンセプト
「レトロな動きと現代的な演出の融合」

- **低フレームレート**: 6-12fpsでレトロ感を演出
- **明確なキーフレーム**: 動きの節目を強調
- **誇張表現**: スマッシュ&ストレッチで躍動感を出す

### 対象範囲
- プレイヤーキャラクター
- 敵キャラクター
- NPCキャラクター
- ダンジョン内の動くオブジェクト

## アニメーション種別

### 必須アニメーション

すべてのキャラクターに実装すべきアニメーション:

#### 1. Idle（待機）
```yaml
フレーム数: 4-6フレーム
フレームレート: 6fps
ループ: あり
用途: 静止時の呼吸や微動を表現
```

**キーフレーム例（4フレーム）:**
1. 基本姿勢
2. わずかに上に（呼吸）
3. 基本姿勢に戻る
4. わずかに下に

#### 2. Walk（歩行）
```yaml
フレーム数: 4-8フレーム
フレームレート: 8fps
ループ: あり
用途: 移動時の基本動作
```

**キーフレーム例（4フレーム）:**
1. 左足前、右足後ろ
2. 両足揃う（中間）
3. 右足前、左足後ろ
4. 両足揃う（中間）

#### 3. Run（走行）
```yaml
フレーム数: 6-8フレーム
フレームレート: 12fps
ループ: あり
用途: ダッシュ時
```

**特徴:**
- Walkより歩幅を大きく
- 体の傾きを強調
- スピード感を出すため残像表現も検討

#### 4. Attack（攻撃）
```yaml
フレーム数: 4-8フレーム
フレームレート: 10fps
ループ: なし
用途: 通常攻撃
```

**キーフレーム例（6フレーム）:**
1. 構え
2. 予備動作（振りかぶり）
3. 攻撃開始
4. 攻撃ヒット（最も強調）
5. 振り抜き
6. 元の姿勢に戻る

#### 5. Hit（被弾）
```yaml
フレーム数: 2-3フレーム
フレームレート: 10fps
ループ: なし
用途: ダメージを受けた時
```

**キーフレーム例（3フレーム）:**
1. のけぞり開始
2. 最大のけぞり（点滅またはフラッシュ）
3. 元に戻る

#### 6. Death（死亡・撃破）
```yaml
フレーム数: 6-10フレーム
フレームレート: 8fps
ループ: なし
用途: HP0時
```

**キーフレーム例（8フレーム）:**
1. 被弾状態
2. よろめき
3. 膝をつく
4. 倒れ始める
5-7. 倒れる過程
8. 完全に倒れた状態（フェードアウト）

### オプショナルアニメーション

余裕があれば実装:

#### 7. Jump（ジャンプ）
```yaml
フレーム数: 4-6フレーム

ループ: なし
```

#### 8. Skill（スキル・必殺技）
```yaml

```

#### 9. Guard（防御）
```yaml

フレームレート: 8fps

```

```yaml
フレーム数: 6-8フレーム
フレームレート: 6fps
```

## アニメーション原則（12の基礎原則から抜粋）

### 1. Squash & Stretch（スマッシュ&ストレッチ）

動きに生命感を与える最重要原則。

**適用例:**
- **ジャンプ**: 上昇中は縦に伸び、着地時は横に潰れる
- **攻撃**: 振りかぶり時は縮み、攻撃時は伸びる
- **被弾**: 衝撃方向に潰れる

```
通常:  ■■    ジャンプ上昇:  ■    着地:  ■■■
      ■■                  ■           ■
      ■■                  ■
                          ■
```

### 2. Anticipation（予備動作）

次の動作を予測させる準備動作。

**適用例:**
- **攻撃前**: 少し後ろに引く
- **ジャンプ前**: 屈む
- **走り出し前**: 構える

### 3. Follow Through（余韨・フォロースルー）

動作後の余韻。

**適用例:**
- **攻撃後**: 振り抜きの慣性
- **着地後**: 揺れ
- **急停止**: スライドして止まる

### 4. Timing（タイミング）

フレームの間隔で速度と重量感を表現。

**フレーム間隔の例:**
```
遅い動き:  ●--●--●--●  （等間隔）
速い動き:  ●●●---●     （加速）
重い動き:  ●---●---●   （ゆっくり）
軽い動き:  ●-●-●-●     （速く細かく）
```

### 5. Exaggeration（誇張）

ドット絵では特に重要。動きを大げさに。

**適用例:**
- **攻撃**: 武器を大きく振りかぶる
- **被弾**: 大きくのけぞる
- **感情**: 喜び・驚きを強調

## フレームレート指針

### 基本フレームレート

```yaml
Idle（待機）:       6fps   // ゆっくりとした呼吸
Walk（歩行）:       8fps   // 落ち着いた移動
Run（走行）:        12fps  // 速い移動
Attack（攻撃）:     10fps  // メリハリのある動き
Hit（被弾）:        10fps  // 素早い反応
Death（死亡）:      8fps   // ドラマチックに
Skill（必殺技）:    10fps  // 派手に
```

### Unity Animatorでの設定

```yaml
Sample Rate: 12（最大フレームレート）
各アニメーションクリップ内でフレームタイミング調整
```

## スプライトシート構成

### レイアウト規則

#### 単一アニメーション（1方向のみ）

```
[Frame1][Frame2][Frame3][Frame4][Frame5][Frame6]
```

横一列に並べる。左から右へ時系列順。

#### 多方向アニメーション（4方向）

```
行1: [Down1][Down2][Down3][Down4]  // 下向き
行2: [Left1][Left2][Left3][Left4]  // 左向き
行3: [Right1][Right2][Right3][Right4] // 右向き
行4: [Up1][Up2][Up3][Up4]          // 上向き
```

#### 多方向アニメーション（8方向）

```
行1: 下（South）
行2: 左下（SouthWest）
行3: 左（West）
行4: 左上（NorthWest）
行5: 上（North）
行6: 右上（NorthEast）
行7: 右（East）
行8: 右下（SouthEast）
```

### スプライトシートサイズ

```yaml
2のべき乗を推奨: 512x512, 1024x1024, 2048x2048
余白: 各スプライト間に1-2px
パディング: シート端から1px
透過: PNG、アルファチャンネルあり
```

### 命名規則

```
キャラ名_アニメーション名_方向_フレーム番号.png

例:
- player_idle_down_0.png
- player_walk_left_0.png
- slime_attack_0.png（方向なしの場合）
```

スプライトシートの場合:
```
キャラ名_アニメーション名_spritesheet.png

例:
- player_idle_spritesheet.png
- slime_walk_spritesheet.png
```

## Unity Animator設定

### Animatorコントローラー構成

```
Assets/Olca/Presentation/Animations/
├── Controllers/
│   ├── PlayerAnimator.controller
│   ├── EnemySlimeAnimator.controller
│   └── BossAnimator.controller
└── Clips/
    ├── Player/
    │   ├── Player_Idle.anim
    │   ├── Player_Walk.anim
    │   ├── Player_Attack.anim
    │   └── ...
    └── Enemies/
        └── ...
```

### ステートマシン設計

#### 基本構造

```
Entry → Idle
Idle → Walk (isWalking = true)
Walk → Idle (isWalking = false)
Any State → Attack (Trigger: attack)
Any State → Hit (Trigger: hit)
Any State → Death (Trigger: death)
```

#### パラメータ定義

```yaml
Bool:
  - isWalking: 歩行中かどうか
  - isRunning: 走行中かどうか

Float:
  - moveSpeed: 移動速度（0-1）
  - directionX: X方向（-1 ~ 1）
  - directionY: Y方向（-1 ~ 1）

Trigger:
  - attack: 攻撃
  - hit: 被弾
  - death: 死亡
  - skill: スキル使用
```

### トランジション設定

```yaml
Has Exit Time: 基本的にfalse（即座に遷移）
Exit Time: 1.0（アニメーション完了時に遷移する場合）
Transition Duration: 0（クロスフェードなし、ドット絵では不要）
Interruption Source: Current State（現在のステートから割り込み可能）
```

### Blend Tree（方向制御）

8方向移動の場合、2D Blend Treeを使用:

```yaml
Blend Type: 2D Simple Directional
Parameters: directionX, directionY

Motions:
  - (0, -1):  Down
  - (-1, -1): SouthWest
  - (-1, 0):  Left
  - (-1, 1):  NorthWest
  - (0, 1):   Up
  - (1, 1):   NorthEast
  - (1, 0):   Right
  - (1, -1):  SouthEast
```

## アニメーションイベント

アニメーションの特定フレームで効果音やエフェクトを発火。

### 使用例

#### 攻撃アニメーション
```yaml
Frame 3（攻撃ヒット時）:
  - Event: OnAttackHit
  - 効果音: SwordSlash.wav
  - エフェクト: SlashEffect
  - ダメージ判定発生
```

#### 足音
```yaml
Walk アニメーション:
  - Frame 0: OnFootstep（左足）
  - Frame 2: OnFootstep（右足）
  - 効果音: Footstep.wav
```

#### 死亡アニメーション
```yaml
Frame 8（完全に倒れた時）:
  - Event: OnDeathComplete
  - ゲームオブジェクト削除処理
```

### Unity実装

```csharp
// アニメーションイベントを受け取るコンポーネント
public class CharacterAnimationEvents : MonoBehaviour
{
    // アニメーションから呼ばれるイベント関数
    public void OnAttackHit()
    {
        // 攻撃ヒット処理
        Debug.Log("攻撃ヒット！");
        // 効果音再生、エフェクト生成等
    }

    public void OnFootstep()
    {
        // 足音再生
        AudioManager.Instance.PlaySE("Footstep");
    }

    public void OnDeathComplete()
    {
        // 死亡完了処理
        Destroy(gameObject);
    }
}
```

## 方向制御

### 4方向制御

```csharp
// 4方向の決定ロジック
public enum Direction4
{
    Down,
    Left,
    Right,
    Up
}

public Direction4 GetDirection4(Vector2 movement)
{
    if (Mathf.Abs(movement.x) > Mathf.Abs(movement.y))
    {
        return movement.x > 0 ? Direction4.Right : Direction4.Left;
    }
    else
    {
        return movement.y > 0 ? Direction4.Up : Direction4.Down;
    }
}
```

### 8方向制御

```csharp
// 8方向の決定ロジック
public enum Direction8
{
    South,
    SouthWest,
    West,
    NorthWest,
    North,
    NorthEast,
    East,
    SouthEast
}

public Direction8 GetDirection8(Vector2 movement)
{
    float angle = Mathf.Atan2(movement.y, movement.x) * Mathf.Rad2Deg;
    if (angle < 0) angle += 360;

    if (angle >= 337.5f || angle < 22.5f) return Direction8.East;
    else if (angle >= 22.5f && angle < 67.5f) return Direction8.NorthEast;
    else if (angle >= 67.5f && angle < 112.5f) return Direction8.North;
    else if (angle >= 112.5f && angle < 157.5f) return Direction8.NorthWest;
    else if (angle >= 157.5f && angle < 202.5f) return Direction8.West;
    else if (angle >= 202.5f && angle < 247.5f) return Direction8.SouthWest;
    else if (angle >= 247.5f && angle < 292.5f) return Direction8.South;
    else return Direction8.SouthEast;
}
```

### 左右フリップ（2方向スプライトの場合）

スプライトが左右のみの場合、SpriteRendererのFlipXを使用:

```csharp
public void UpdateDirection(Vector2 movement)
{
    if (movement.x > 0)
        spriteRenderer.flipX = false; // 右向き
    else if (movement.x < 0)
        spriteRenderer.flipX = true;  // 左向き
}
```

**注意:** フリップはドット絵の非対称性を壊す可能性があるため、可能な限り左右別スプライトを推奨。

## パフォーマンス最適化

### Sprite Atlas使用

同じキャラクターのスプライトは1つのAtlasにまとめる:

```
Assets/Olca/Art/Sprites/Atlases/
├── PlayerAtlas.spriteatlas
├── EnemiesAtlas.spriteatlas
└── NPCAtlas.spriteatlas
```

効果:
- Draw Call削減
- メモリ効率向上
- ロード時間短縮

### Animator最適化

```yaml
Culling Mode: Cull Update Transforms
  - 画面外のキャラクターはアニメーション更新を停止

Optimize Game Objects: チェック
  - Transform階層を最適化
```

### アニメーションクリップ最適化

```yaml
不要なカーブ削除: Position.z等、使わないプロパティ
キーフレーム削減: 変化のないフレームを削除
```

## FAQ

### Q: すべてのキャラクターに8方向が必要ですか？
A: いいえ。プレイヤーは8方向推奨、雑魚敵は4方向、一部敵は2方向（左右フリップ）でも可。

### Q: アニメーション途中でキャンセルできるようにするには？
A: Animatorのトランジション設定で「Has Exit Time」をfalseに、「Interruption Source」を適切に設定。

### Q: ループアニメーションが滑らかに繋がりません
A: 最終フレームを最初のフレームと同じにするか、中間フレームを調整してスムーズに繋げる。

### Q: Unity Animatorを使わず、スクリプトで制御できますか？
A: 可能ですが、Animatorの方が管理しやすいため推奨しません。単純なアニメーションのみスクリプト制御も可。
