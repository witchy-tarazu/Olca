# ドットアート仕様 - Olca

## 概要

本ドキュメントは、Olcaプロジェクトにおけるドット絵制作の技術仕様とルールを定めます。
ドット絵はゲームの主要なビジュアル要素であり、統一感と品質を保つために本仕様に従ってください。

---

## 基本方針

### コンセプト
「現代的な解釈のレトロドット絵」

- クラシックなドット絵の温かみを保ちつつ
- 現代的な配色とディテールで洗練された印象に
- ピクセルパーフェクトを徹底

### 対象範囲
以下の要素にドットアートを使用します:

- ✅ プレイヤーキャラクター
- ✅ 敵キャラクター
- ✅ ダンジョンマップタイル
- ✅ オブジェクト（宝箱、扉、罠等）
- ✅ アイテムアイコン
- ✅ 一部のバトルエフェクト

## 技術仕様

### 解像度基準

プロジェクト内で使用するドット絵は、以下のサイズ規格に準拠してください。

#### キャラクタースプライト
```
小型キャラ（雑魚敵等）:  32x32px
中型キャラ（プレイヤー等）: 64x64px
大型キャラ（ボス等）:     128x128px または 128x192px
超大型キャラ:           256x256px（特別な場合のみ）
```

#### タイルセット
```
基本タイル: 16x16px（ダンジョン床、壁等）
大型タイル: 32x32px（特殊オブジェクト）
```

#### アイテム・アイコン
```
小アイコン: 32x32px（インベントリ）
中アイコン: 64x64px（カードアイコン）
大アイコン: 128x128px（詳細表示）
```

#### エフェクト
```
小エフェクト: 64x64px（ヒット時の火花等）
中エフェクト: 128x128px（爆発等）
大エフェクト: 256x256px（必殺技等）
```

### カラーパレット

#### パレット制限
- **1スプライトあたり最大32色**
  - 透明色を含む
  - アウトライン色を含む
- **パレット共有を推奨**
  - 同じカテゴリのスプライトは同一パレットを使用
  - 例: すべてのプレイヤーキャラは共通16色パレット

#### 推奨パレット構成

**プレイヤー・味方キャラ用パレット（16色）**
```
透明:       #00000000
アウトライン: #1A1A1A（ダークグレー）
影色1:      #3E2723（ダークブラウン）
影色2:      #5D4037
ベース色1:  #8D6E63
ベース色2:  #A1887F
ハイライト1: #BCAAA4
ハイライト2: #D7CCC8

アクセント1: #E74C3C（赤系）
アクセント2: #3498DB（青系）
金属1:      #5A5A5A
金属2:      #8E8E8E
金属HL:     #C0C0C0

白系1:      #ECEFF1
白系2:      #FFFFFF
特殊色:     #F39C12（任意）
```

**敵キャラ用パレット（16色）**
```
透明:       #00000000
アウトライン: #1A1A1A
影色:       #4A148C（ダークパープル）
ベース色1:  #6A1B9A
ベース色2:  #8E24AA
ハイライト1: #AB47BC
ハイライト2: #CE93D8

敵アクセント1: #D32F2F（赤）
敵アクセント2: #7B1FA2（紫）
金属等:     (プレイヤーと共通)
```

#### 色数削減テクニック
- **限定パレットの活用**: 意図的に色数を減らして統一感を出す
- **ディザリング**: 2色を混ぜて中間色を表現
- **ハーフトーン**: 網点パターンで濃淡表現

## アンチエイリアス規則

### 基本原則: **アンチエイリアス禁止**

ドット絵の鮮明さを保つため、原則としてアンチエイリアスは使用しません。

#### ❌ 禁止事項
- Photoshopのブラシツールでのぼかし
- 自動スムージング機能の使用
- 中間色による輪郭のぼかし

#### ✅ 例外的に許可されるケース
以下の場合、**手動で配置した限定的なアンチエイリアス**のみ許可:

1. **大型スプライト（64px以上）の曲線**
   - 滑らかな曲線を表現するため、エッジに1-2px程度の中間色配置
   - 使用する中間色は最大2色まで

2. **回転が必要なスプライト**
   - Unityで回転させる場合、事前に軽いAAを適用可能
   - ただし、回転させない前提で制作することを推奨

## アウトライン（輪郭線）

### アウトライン方針

ドット絵の視認性と存在感を高めるため、基本的に **アウトライン有り** で制作します。

#### アウトライン色
```
標準アウトライン: #1A1A1A（ダークグレー、純黒ではない）
明るい背景用:    #0D0D0D（より暗く）
暗い背景用:      #3E3E3E（やや明るく）
```

- **純黒（#000000）は使用しない**: 硬すぎる印象を避けるため
- **選択的アウトライン**: 内部の細かいパーツにはアウトラインを省略可

#### アウトライン太さ
```
小型スプライト（32x32px）:  1px
中型スプライト（64x64px）:  2px
大型スプライト（128px以上）: 2-3px
```

### セルディング（Cel-shading）スタイル

影の表現には、段階的な塗り分けを使用します。

**推奨段数:**
- 小型スプライト: 2段階（ベース + 影1）
- 中型スプライト: 3段階（ベース + 影1 + 影2）
- 大型スプライト: 4-5段階（ベース + 影2-3 + ハイライト）

**NG例:**
- ❌ グラデーションツールで自動生成
- ❌ 10段階以上の細かすぎる影

## アニメーション仕様

### フレーム数ガイドライン

ドット絵アニメーションは、レトロ感を保つため **低フレームレート** で制作します。

#### 推奨フレーム数
```
待機（Idle）:       4-6フレーム
歩行（Walk）:       4-8フレーム
走行（Run）:        6-8フレーム
攻撃（Attack）:     4-8フレーム
被弾（Hit）:        2-3フレーム
死亡（Death）:      6-10フレーム
```

#### フレームレート
```
通常アニメーション: 8fps（1フレーム=125ms）
速い動作:          12fps（1フレーム=83ms）
ゆっくりした動作:   6fps（1フレーム=167ms）
```

### アニメーションの原則

#### 1. スマッシュ&ストレッチ（Squash & Stretch）
- ジャンプ時: 上昇中は縦に伸び、着地時は横に潰れる
- 攻撃時: 振りかぶりで縮み、攻撃瞬間で伸びる

#### 2. アンティシペーション（予備動作）
- 攻撃前に少し後ろに引く
- ジャンプ前に屈む

#### 3. フォロースルー（余韻）
- 攻撃後の振り抜き
- 着地後の揺れ

#### 4. イージング（緩急）
- 等間隔ではなく、加速・減速を意識
- キーフレームの間隔を調整

詳細は [キャラクターアニメーション仕様.md](キャラクターアニメーション仕様.md) を参照してください。

## スプライトシート構成

### レイアウト規則

アニメーションフレームは、横一列または格子状に配置します。

#### 推奨レイアウト
```
横一列（1方向のみ）:
[Frame1][Frame2][Frame3][Frame4]

格子状（4方向）:
[Down1][Down2][Down3][Down4]
[Left1][Left2][Left3][Left4]
[Right1][Right2][Right3][Right4]
[Up1][Up2][Up3][Up4]
```

#### 方向の順序（8方向の場合）
```
1行目: 下向き（South）
2行目: 左下（SouthWest）
3行目: 左向き（West）
4行目: 左上（NorthWest）
5行目: 上向き（North）
6行目: 右上（NorthEast）
7行目: 右向き（East）
8行目: 右下（SouthEast）
```

### スプライトシートサイズ

- **2のべき乗サイズを推奨**: 256x256, 512x512, 1024x1024px等
- **余白**: 各スプライト間に1-2pxの余白を確保
- **パディング**: シート端から1pxの余白

### ピボットポイント

スプライトの基準点（Pivot）は以下を推奨:

```
キャラクター: 足元中央（X: 0.5, Y: 0）
    - 地面との接地を明確にするため

エフェクト: 中央（X: 0.5, Y: 0.5）
    - 回転・拡大縮小の基準として

UI アイコン: 中央（X: 0.5, Y: 0.5）
```

## タイルセット仕様

### タイルサイズ
```
基本タイル: 16x16px
```

### タイルセット構成

#### 床タイル
- 基本床: 9パターン（中央 + 8方向のバリエーション）
- コーナー: 内角4パターン、外角4パターン
- 特殊床: 水、溶岩、草地等

#### 壁タイル
- 正面壁: 1パターン
- 側面壁: 左右2パターン
- コーナー壁: 内角4パターン、外角4パターン
- 装飾壁: 窓、扉、ひび割れ等

### オートタイル（Auto-tile）

Unity Tilemapのルールタイル機能を活用します。

**ルールタイルパターン:**
- 47パターン（完全オートタイル）
- または16パターン（簡易版）

詳細な配置ルールは別途Tilemapドキュメントを参照してください。

## ドット絵制作ワークフロー

### 1. 下絵作成
1. ラフスケッチ（紙またはデジタル）
2. サイズ確認（16x16, 32x32等）
3. アウトラインの配置

### 2. カラーパレット設定
1. 既存パレットの確認
2. 新規の場合、16-32色以内でパレット作成
3. パレットを保存（.ase, .gpl等）

### 3. 塗り
1. ベース色で塗りつぶし
2. 影色を配置（2-3段階）
3. ハイライトを追加
4. ディテール追加

### 4. アニメーション作成
1. キーフレームを作成
2. 中間フレームを追加
3. タイミング調整（6-12fps）
4. ループ確認

### 5. 出力
1. スプライトシートとして出力
2. PNG形式、透過あり
3. フィルタリング: Point (no filter)

### 6. Unity インポート
1. Texture Type: Sprite (2D and UI)
2. Pixels Per Unit: 16（タイルサイズに合わせる）
3. Filter Mode: Point (no filter)
4. Compression: None（ドット絵は圧縮しない）

## ドット絵のベストプラクティス

### ✅ 推奨テクニック

#### 1. クラスタリング（Clustering）
- ピクセルを孤立させず、2-3個のまとまりで配置
- 視認性が向上

#### 2. ディザリング（Dithering）
```
パターン1（50%）:  パターン2（25%）:
■□■□              ■□□□
□■□■              □□□■
■□■□              □■□□
□■□■              □□□□
```

#### 3. セレクティブアウトライン
- すべての境界線を囲まず、重要な部分のみアウトライン
- 内部ディテールは色の差で表現

#### 4. ピクセルパーフェクト
- 1pxのズレも許さない丁寧な配置
- ブラシサイズ1px、グリッドスナップON

### ❌ 避けるべき表現

#### 1. ジャギー（Jaggies）
- 階段状のガタガタした斜め線
- 解決策: 適切なアンチエイリアス配置（手動）

#### 2. ピローシェーディング（Pillow Shading）
- 輪郭に沿って影を配置する初心者的手法
- 解決策: 光源を意識した影の配置

#### 3. バンディング（Banding）
- グラデーションが縞模様になる
- 解決策: 中間色を適切に配置、ディザリング活用

## Unity連携設定

### Sprite Import設定

```yaml
Texture Type: Sprite (2D and UI)
Sprite Mode: Multiple（スプライトシートの場合）
Pixels Per Unit: 16  # タイルサイズに合わせる
Mesh Type: Tight
Extrude Edges: 0
Pivot: Custom（キャラクターは Bottom）
Generate Physics Shape: チェックを外す

Advanced:
  sRGB: チェックあり
  Alpha Source: Input Texture Alpha
  Alpha Is Transparency: チェックあり

Filter Mode: Point (no filter)  # 重要！
Compression: None
Max Size: 2048
```

### Sprite Renderer設定

```yaml
Material: Sprites/Default
Color: (255, 255, 255, 255)
Flip: 使用しない（アニメーションで対応）
Sorting Layer: Character / Enemy 等
Order in Layer: Y座標で動的変更
```

### Pixel Perfect Camera

Pixel Perfect Cameraコンポーネントを使用してピクセルパーフェクト表示を実現:

```yaml
Reference Resolution: 1920x1080
Assets Pixels Per Unit: 16
Upscale Render Texture: チェックあり
Pixel Snapping: チェックあり
Crop Frame: チェックなし
Stretch Fill: チェックなし
```

## FAQ

### Q: Photoshopで作成してもいいですか？
A: 可能ですが、以下の設定を必ず守ってください:
- Pencilツールのみ使用
- グリッド表示（16px間隔）
- スナップ機能ON
- アンチエイリアスOFF

### Q: 既存のドット絵素材を流用できますか？
A: 以下の条件を満たす場合のみ可:
- ライセンス的に問題ない
- 本プロジェクトのパレット・サイズ規格に適合
- 既存アセットとの統一感がある

### Q: 32色を超えるスプライトは絶対にNGですか？
A: 以下の場合、例外的に許可されます:
- 64x64px以上の大型スプライト
- ボスキャラ等の特別な存在
- 最大64色まで

### Q: アニメーションのフレーム数を増やしたいです
A: ゲームの雰囲気を保つため、原則8フレーム以内を推奨します。
滑らかさよりも、レトロゲームの「カクカク感」を意図的に残します。
