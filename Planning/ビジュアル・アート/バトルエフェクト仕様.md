# バトルエフェクト仕様 - Olca

## 概要

本ドキュメントは、Olcaプロジェクトのバトルシーンにおける視覚効果（エフェクト）の仕様を定めます。
エフェクトは **ドット絵** と **通常イラスト** の両方を使い分け、戦闘の迫力と爽快感を演出します。

---

## エフェクトの役割

### 目的
- **視覚的フィードバック**: 攻撃のヒット感、ダメージの表現
- **戦闘の迫力**: 派手な演出で爽快感を演出
- **情報伝達**: 状態異常、バフ・デバフの視覚化

### 設計方針
- **ドット絵**: 小規模エフェクト、レトロ感
- **通常イラスト**: 大規模エフェクト、派手な演出
- **パーティクルシステム**: 細かい粒子、光の表現

## ドット絵エフェクトの制作仕様

### 基本仕様

```yaml
解像度: 64x64px ~ 256x256px
カラー: フルカラー（32色制限なし、エフェクトは例外）
フレーム数: 4-12フレーム
フレームレート: 12-15fps（通常のドット絵より高速）
フォーマット: PNG（透過あり）
```

### エフェクトの特徴

#### 1. 高彩度・高輝度
- 通常のドット絵より派手な色使い
- 白色のハイライトを多用
- グロー効果（Unity側で追加）

#### 2. アニメーション原則
```
1. 小さく始まる
2. 一瞬で最大に
3. 素早く消える

例（斬撃エフェクト、6フレーム）:
Frame 1: 10%サイズ
Frame 2: 50%サイズ
Frame 3: 100%サイズ（最も明るい）
Frame 4: 80%サイズ、やや透明
Frame 5: 50%サイズ、半透明
Frame 6: 20%サイズ、ほぼ透明
```

#### 3. 残像・モーションブラー
- 軌跡を残して動きを表現
- 後ろのフレームを薄く残す

### ドット絵エフェクトの例

#### 斬撃エフェクト（64x64px、6フレーム）

```
Frame 1:    Frame 2:    Frame 3:
  /           //          ///
              /           //
                          /

Frame 4:    Frame 5:    Frame 6:
 ///         //          /
 //          /
 /

色: 白 → 水色 → 透明
```

## 通常イラストエフェクトの制作仕様

### 基本仕様

```yaml
解像度: 128x128px ~ 512x512px
スタイル: アニメ調、発光表現多用
フレーム数: 8-15フレーム
フレームレート: 15fps
フォーマット: PNG（透過あり）
```

### 制作テクニック

#### 1. 発光表現
- 中心部を白く、外側にかけてグラデーション
- 加算合成（Additive Blending）を想定
- Unity側でBloom効果を適用

#### 2. グラデーション
- 滑らかなグラデーション（ドット絵とは異なる）
- 複数色のグラデーション（例: 赤 → オレンジ → 黄色 → 白）

#### 3. ディテール
- エネルギーの流れ、渦、波紋等を表現
- 細かい粒子、火花を散らす

### 通常イラストエフェクトの例

#### 炎エフェクト（256x256px、12フレーム）

```
フレーム構成:
1-3: 小さな火が発生
4-6: 炎が大きく燃え上がる
7-9: 最大の炎
10-12: 炎が消えていく

レイヤー構成:
- 外炎（赤 → オレンジ）
- 内炎（オレンジ → 黄色）
- 中心（黄色 → 白）
- 火花パーティクル
```

細かい粒子、光、煙等はUnityのParticle Systemで実装。

### 基本設定

#### 攻撃ヒット時のパーティクル

```yaml
Emission:
  Rate over Time: 0
  Bursts: 1回、30-50粒子

Start Lifetime: 0.3-0.5秒
Start Speed: 3-5
Start Size: 0.1-0.3
Start Color: 白 → 半透明

Shape:
  Shape: Sphere
  Radius: 0.5

Color over Lifetime: 白 → 透明
Size over Lifetime: 大 → 小

Renderer:
  Material: Additive（加算合成）
  Texture: 丸いグロー
```

#### 持続バフのパーティクル

```yaml
Emission:
  Rate over Time: 10-20粒子/秒

Start Lifetime: 1-2秒
Start Speed: 0.5-1
Start Size: 0.1-0.2
Start Color: バフに応じた色

Shape:
  Shape: Cone（上向き）
  Angle: 10度

Color over Lifetime: 色 → 透明
Velocity over Lifetime: 上向きに加速

Renderer:
  Material: Additive
  Texture: 星形、光の粒
```

## 画面効果（Screen Effects）

### フラッシュ

画面全体を一瞬光らせる。

```yaml
用途: クリティカル、必殺技
色: 白
持続時間: 100ms
アニメーション: フェードイン（50ms）→ フェードアウト（50ms）
```

### シェイク（画面揺れ）

画面を揺らして衝撃を表現。

```yaml
用途: 大ダメージ、爆発
揺れ幅: 10-20px
持続時間: 200-400ms
周波数: 30Hz
減衰: 徐々に小さく
```

### スローモーション

時間をゆっくりにして強調。

```yaml
用途: 必殺技ヒット時
スケール: 0.2-0.5倍速
持続時間: 300-500ms
イージング: Ease In Out
```

### ズームイン/アウト

カメラをズームして強調。

```yaml
用途: 必殺技発動時
ズーム倍率: 1.2-1.5倍
持続時間: 500ms
イージング: Ease Out
```

### カラーグレーディング

画面の色調を変更。

```yaml
用途: 毒状態（画面が紫がかる）、炎属性攻撃（画面が赤く）
強度: 10-30%
持続時間: 200-500ms
```

### エフェクトマネージャー

```csharp
// EffectManager.cs
public class EffectManager : MonoBehaviour
{
    private static EffectManager instance;
    public static EffectManager Instance => instance;

    [SerializeField] private Dictionary<string, GameObject> effectPrefabs;

    private void Awake()
    {
        instance = this;
    }

    public void PlayEffect(string effectName, Vector3 position, Quaternion rotation = default)
    {
        if (effectPrefabs.TryGetValue(effectName, out GameObject prefab))
        {
            GameObject effect = Instantiate(prefab, position, rotation);
            // エフェクト終了後に自動削除
            Destroy(effect, GetEffectDuration(effect));
        }
    }

    private float GetEffectDuration(GameObject effect)
    {
        // Animatorやパーティクルから持続時間を取得
        var animator = effect.GetComponent<Animator>();
        if (animator != null)
        {
            return animator.GetCurrentAnimatorStateInfo(0).length;
        }

        var particle = effect.GetComponent<ParticleSystem>();
        if (particle != null)
        {
            return particle.main.duration;
        }

        return 1.0f; // デフォルト
    }
}
```

### マテリアル設定

#### 加算合成マテリアル（Additive.mat）

```yaml
Shader: Sprites/Default
Rendering Mode: Additive（カスタムシェーダーで実装）
Color: (1, 1, 1, 1)
```

カスタムシェーダー（Additive Sprite）:

```shader
Shader "Custom/AdditiveSprite"
{
    Properties
    {
        _MainTex ("Sprite Texture", 2D) = "white" {}
        _Color ("Tint", Color) = (1,1,1,1)
    }

    SubShader
    {
        Tags
        {
            "Queue"="Transparent"
            "RenderType"="Transparent"
        }

        Blend One One // 加算合成
        ZWrite Off
        Cull Off

        Pass
        {
            CGPROGRAM
            #pragma vertex vert
            #pragma fragment frag

            #include "UnityCG.cginc"

            sampler2D _MainTex;
            fixed4 _Color;

            struct appdata
            {
                float4 vertex : POSITION;
                float2 uv : TEXCOORD0;
                fixed4 color : COLOR;
            };

            struct v2f
            {
                float4 vertex : SV_POSITION;
                float2 uv : TEXCOORD0;
                fixed4 color : COLOR;
            };

            v2f vert(appdata v)
            {
                v2f o;
                o.vertex = UnityObjectToClipPos(v.vertex);
                o.uv = v.uv;
                o.color = v.color * _Color;
                return o;
            }

            fixed4 frag(v2f i) : SV_Target
            {
                fixed4 col = tex2D(_MainTex, i.uv) * i.color;
                return col;
            }
            ENDCG
        }
    }
}
```

## パフォーマンス最適化

### エフェクト数の制限

```csharp
// EffectManager.cs
private const int MAX_ACTIVE_EFFECTS = 20;
private List<GameObject> activeEffects = new List<GameObject>();

public void PlayEffect(string effectName, Vector3 position)
{
    // 上限チェック
    if (activeEffects.Count >= MAX_ACTIVE_EFFECTS)
    {
        // 最も古いエフェクトを削除
        Destroy(activeEffects[0]);
        activeEffects.RemoveAt(0);
    }

    // エフェクト生成
    GameObject effect = Instantiate(effectPrefab, position, Quaternion.identity);
    activeEffects.Add(effect);
}
```

### オブジェクトプーリング

頻繁に使うエフェクトはプーリング:

```csharp
// EffectPool.cs
public class EffectPool : MonoBehaviour
{
    private Queue<GameObject> pool = new Queue<GameObject>();
    [SerializeField] private GameObject prefab;
    [SerializeField] private int initialSize = 10;

    private void Start()
    {
        for (int i = 0; i < initialSize; i++)
        {
            GameObject obj = Instantiate(prefab);
            obj.SetActive(false);
            pool.Enqueue(obj);
        }
    }

    public GameObject Get()
    {
        if (pool.Count > 0)
        {
            GameObject obj = pool.Dequeue();
            obj.SetActive(true);
            return obj;
        }
        else
        {
            return Instantiate(prefab);
        }
    }

    public void Return(GameObject obj)
    {
        obj.SetActive(false);
        pool.Enqueue(obj);
    }
}
```

## FAQ

### Q: すべてのエフェクトをドット絵で作るのは大変ですか？
A: はい。そのため、小規模エフェクトはドット絵、大規模エフェクトは通常イラストと使い分けます。

### Q: パーティクルシステムは必須ですか？
A: オプションですが、細かい粒子表現にはパーティクルが効率的です。

### Q: 加算合成とアルファブレンドの使い分けは？
A: 光るエフェクトは加算合成、煙や霧等はアルファブレンドを使用。

### Q: エフェクトが多すぎてパフォーマンスが悪いです
A: エフェクト数の上限設定、オブジェクトプーリング、パーティクル数削減を検討してください。
