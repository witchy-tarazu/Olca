# UIデザイン仕様 - Olca

## 概要

本ドキュメントは、Olcaプロジェクトにおけるユーザーインターフェース（UI）のデザイン仕様を定めます。
すべてのUI要素は **フラットデザイン** を基調とし、視認性・操作性・統一感を重視します。

---

## デザインコンセプト

### フラットデザインの原則

「シンプル、明快、機能的」

#### ✅ フラットデザインの特徴
- **2次元的表現**: 影やグラデーションを最小限に
- **明確な色分け**: 境界線と色でエリアを区別
- **シンプルなアイコン**: 装飾を省いた記号的表現
- **読みやすいタイポグラフィ**: 大きめのフォント、十分な余白

#### ❌ 避けるべき表現
- スキューモーフィズム（現実の質感を模倣）
- 過度なドロップシャドウ
- グラデーションの多用
- 3D的な立体表現
- 過剰な装飾・テクスチャ

## タイポグラフィ

### フォントファミリー

#### 日本語フォント
```
メインフォント: Noto Sans JP Regular
太字: Noto Sans JP Bold
見出し: Noto Sans JP Medium
```

#### 英数字・記号
```
数値表示: Roboto Condensed
タイトル: Press Start 2P（ドット風、限定的に使用）
```

### フォントサイズ階層

```
H1 (大見出し):    48px  // タイトル画面
H2 (中見出し):    32px  // セクション見出し
H3 (小見出し):    24px  // サブセクション
Body (本文):      18px  // 通常テキスト
Small (小文字):   14px  // 補足情報
Caption (極小):   12px  // キャプション、注釈
```

### 行間・字間

```
行間（Line Height）:
  - 見出し: フォントサイズ × 1.2
  - 本文: フォントサイズ × 1.5
  - 密集テキスト: フォントサイズ × 1.3

字間（Letter Spacing）:
  - 通常: 0px
  - 見出し: 2-4px（大きい見出しほど広く）
  - キャプション: 1px
```

### テキストの配置

```
左寄せ: 説明文、リスト
中央揃え: タイトル、ボタンラベル
右寄せ: 数値（HP、コスト等）
```

## UIコンポーネントカタログ

### ボタン

#### プライマリボタン（主要アクション）

```yaml
サイズ:
  - 最小: 48px 高さ（タッチ操作対応）
  - 推奨: 160px × 56px
  - 大型: 240px × 64px

スタイル:
  背景色: #3498DB（ミディアムブルー）
  テキスト色: #FFFFFF
  角丸: 4px
  枠線: なし
  パディング: 16px 横、12px 縦

ホバー時:
  背景色: #5DADE2（ライトブルー）
  トランジション: 0.2s ease

押下時:
  背景色: #2980B9（やや暗いブルー）
  Transform: scale(0.98)

非アクティブ時:
  背景色: #BDC3C7（ライトグレー）
  テキスト色: #7F8C8D
  カーソル: not-allowed
```

```yaml
  背景色: #3498DB
```

## レイアウトシステム

### グリッドシステム

UIレイアウトは **8pxグリッド** を基準とします。

```
基本単位: 8px
余白サイズ: 8px, 16px, 24px, 32px, 48px, 64px
要素サイズ: 8の倍数（例: 48px, 56px, 64px）
```

### スペーシング（余白）

```yaml
極小: 4px   // アイコンとテキストの間
小: 8px     // 密接した要素間
中: 16px    // 通常の要素間
大: 24px    // セクション内の余白
特大: 32px  // セクション間の余白
巨大: 48px  // 大きなセクション間
```

### 画面マージン

```yaml
セーフエリア: 画面端から5%
最小マージン: 16px（モバイル）
推奨マージン: 32px（デスクトップ）
```

### レスポンシブ対応

```yaml
基本解像度: 1920x1080
最小対応: 1280x720
UI Anchor: 適切にアンカーを設定してスケール対応
```

## アニメーション・トランジション

### 基本原則

- **速度**: UIアニメーションは100-300ms
- **イージング**: 自然な動きを意識
- **フィードバック**: 操作に対して即座に反応

### イージングカーブ

```yaml
Ease Out: UI表示（素早く表示、ゆっくり停止）
  - 用途: パネル表示、フェードイン
  - 曲線: cubic-bezier(0.25, 0.46, 0.45, 0.94)

Ease In: UI非表示（ゆっくり開始、素早く消失）
  - 用途: パネル非表示、フェードアウト
  - 曲線: cubic-bezier(0.55, 0.085, 0.68, 0.53)

Ease In Out: 強調・変化（滑らかな加速減速）
  - 用途: ホバー、選択状態変化
  - 曲線: cubic-bezier(0.42, 0, 0.58, 1)

Elastic: バウンド効果（弾むような動き）
  - 用途: 重要な通知、達成演出
  - 曲線: cubic-bezier(0.68, -0.55, 0.265, 1.55)
```

### アニメーションパターン

#### ボタンクリック
```yaml
Duration: 100ms
アニメーション:
  - Scale: 1.0 → 0.98 → 1.0
  - 色: 通常 → 押下色
```

#### パネル表示
```yaml
Duration: 200ms
アニメーション:
  - フェードイン: Opacity 0 → 1
  - スライド: Transform Y -20px → 0px
  - イージング: Ease Out
```

#### パネル非表示
```yaml
Duration: 150ms
アニメーション:
  - フェードアウト: Opacity 1 → 0
  - スライド: Transform Y 0px → 20px
  - イージング: Ease In
```

#### ホバーエフェクト
```yaml
Duration: 200ms
アニメーション:
  - 色変化: 通常 → ホバー色
  - 影強調（カードの場合）
  - イージング: Ease In Out
```

#### ゲージ増減
```yaml
Duration: 300ms（減少）、500ms（増加）
アニメーション:
  - Width変化: 滑らかに
  - 色変化: HP量に応じて
  - イージング: Ease Out
```

## アクセシビリティ

### 色覚異常対応

- **色のみに依存しない**: 形状・アイコンでも区別可能に
- **コントラスト比**: 最低4.5:1（WCAG AA基準）
- **色覚シミュレーション**: 1型・2型色覚でテスト

### タッチ操作対応

```yaml
最小タッチサイズ: 48x48px
要素間の間隔: 最低8px（誤タップ防止）
```

### キーボード操作

- **Tabキー**: フォーカス移動
- **Enterキー**: 決定
- **Escapeキー**: キャンセル・閉じる

## Unity実装ガイド

### UI Toolkit vs uGUI

本プロジェクトでは **uGUI（Unity UI）** を使用します。

理由:
- Spriteとの統合が容易
- アニメーション制御が直感的
- 2Dゲームとの相性が良い

### Canvas設定

```yaml
Render Mode: Screen Space - Overlay
UI Scale Mode: Scale With Screen Size
Reference Resolution: 1920x1080
Screen Match Mode: Match Width Or Height
Match: 0.5（幅と高さの中間）
```

```csharp

    public Color special = new Color(0.61f, 0.35f, 0.71f);  // #9B59B6
```

## デザインチェックリスト

UIデザイン完了時、以下を確認してください:

- [ ] フラットデザインの原則に従っているか
- [ ] カラースキームが統一されているか
- [ ] フォントサイズ・行間が読みやすいか
- [ ] 8pxグリッドに沿って配置されているか
- [ ] ボタンのタッチサイズが48px以上か
- [ ] ホバー・クリック時のフィードバックがあるか
- [ ] アニメーションが100-300msの範囲か
- [ ] コントラスト比が4.5:1以上か
- [ ] 色のみに依存せず、形状でも区別可能か
- [ ] 命名規則に従っているか
