# カスタム画面仕様 - Olca

## 概要

本ドキュメントは、バトルシステムにおける「カスタム画面」の詳細仕様を定義します。
カスタム画面は、プレイヤーが戦闘中に一時的に手札を選択し、特殊な行動を行うための専用UIです。

**本ドキュメントの目的**:
- デザイナー・プランナーがカスタム画面の見た目と動作を正確に理解する
- UI/UXの詳細仕様を明確化する
- アニメーションのタイミングと演出を定義する

**重要な注意事項**:
- **本ドキュメントはビジュアル・UI仕様のみを扱います**
- **ゲーム性・ロジック仕様（コスト計算、選択制限ルール等）は含みません**
- ゲームシステムの詳細は `Planning/バトルシステムについて` を参照してください
- 技術的な実装コードは別途設計ドキュメントを参照してください

## カスタム画面とは

### 基本コンセプト

**カスタム画面**は、バトル中に「カスタムゲージ」が満タンになったときに表示される特殊な画面です。
プレイヤーは手札からカードを選択し、強力な「カスタム行動」を実行できます。

### ゲームフロー

```
通常バトル中
  ↓
カスタムゲージが満タンになる
  ↓
カスタム画面へ移行（アニメーション開始）
  ↓
プレイヤーがカードを選択
  ↓
「確定」ボタンを押す
  ↓
カスタム画面から通常バトルへ戻る（アニメーション開始）
  ↓
選択したカードの効果が発動
  ↓
通常バトル再開
```

### 画面の役割

- **通常バトルからの切り替え**: ゲージ満タン時に自動的に表示
- **カード選択**: 手札から複数枚のカードを選択可能
- **視覚的な強調**: 特別な演出により「強力な行動」であることを伝える
- **通常バトルへの復帰**: 確定後、元の画面に戻る

## 画面構成

### 全体レイアウト

カスタム画面表示時の画面構成:
HP表示とカスタムゲージはカスタム画面と一体化しており、カスタムゲージが画面外にある間も表示が見える位置にあります。

```
┌─────────────────────────────────────┐────────────────┐
│     【選択カード表示エリア】          │  [HP: 100/100] │← HP表示（左上、常に表示）
│    ┌──────────────────────────┐     │────────────────┘
│    │ 【イラスト】 │【簡易説明】 │     │    │
│    │             │            │     │ カ │
│    │             │            │     │ ー │
│    └──────────────────────────┘     │ ス │
│     【カスタム画面エリア】            │ タ │
│    ┌──────────────────────────┐     │ ム │
│    │  [カード1] [カード2] ...  │     │ ゲ │
│    │  [カード5] [カード6] ...  │     │ ー │
│    └──────────────────────────┘     │ ジ │
│                                     │    │
│            [確定ボタン]              │    │
└─────────────────────────────────────┘────┘
```

### UI要素の配置

#### 1. HPゲージ
- **位置**: 画面左上（カスタム画面表示時は画面中央上部）
- **状態**: 常に表示

#### 2. カスタムゲージ
- **位置**: 画面左端（ カスタム画面表示時は画面中央）
- **方向**: 縦置き、下から上へ増加
- **状態**: カスタム画面表示時は上に文字を載せる

#### 3. カスタム画面エリア
- **位置**: 画面左下部

#### 4. 手札選択エリア
- **位置**: カスタム画面エリアの下
- **レイアウト**: 5x2グリッド（最大10枚想定）

#### 5. 確定ボタン
- **位置**: カスタム画面エリアの下部中央
- **ラベル**: "確定"

#### 6. 選択カード表示エリア
- **位置**: 画面左上部
- **レイアウト**: 左方に選択カードのイラスト、右方に選択カードの説明

## デザイン詳細

### カスタム画面エリアのスタイル

- **背景オーバーレイ**: 半透明の黒、全画面を覆う
- **カスタムパネル**: ダークブルー背景、ライトブルーの枠線
- **タイトルテキスト**（オプション）: "カスタム行動"

### 手札カードのスタイル

#### 通常状態
- 白背景、グレーの枠線

#### ホバー時
- 枠線が青に変化、わずかに拡大

#### 選択時
- **青背景、白テキスト**
- **右上にチェックマーク表示**
- 影がより強調

#### 非選択時（選択上限到達時）
- グレーアウト、半透明

### 確定ボタンのスタイル

#### 通常状態
- 青背景、白テキスト

#### ホバー時
- より明るい青に変化

#### 押下時
- わずかに縮小

#### 非アクティブ時
- グレーアウト

## アニメーション仕様

### 1. カスタム画面への移行アニメーション

カスタムゲージが満タンになった後、ユーザーがカスタムゲージを開く操作をしたとき、以下のアニメーションが同時に実行されます。

#### アニメーション概要

- **カスタム画面全体の表示**: 画面外から画面左へスライド（スライドインの際に一瞬右側にオーバーランしてから定位置へ戻り、ポップな印象を付ける）
- **手札カードの表示**: 左方から射出され、回転しながら矩形の中を2回バウンドして定位置へ移動、定位置に収まる際には回転角が0度になるように回転量を調整
- **カスタムゲージ上に文字を表示**:カスタムゲージの上に準備中を示す文字を表示 

### 2. カード選択時のアニメーション

#### 選択アニメーション
- 枠線と背景が青に変化
- わずかに拡大してから元に戻る
- 右上にチェックマークが表示される
- **所要時間**: 約0.2秒

#### 選択解除アニメーション
- 枠線と背景が元に戻る
- チェックマークが消える
- **所要時間**: 約0.15秒

### 3. 確定ボタン押下時のアニメーション

- ボタンがわずかに縮小
- 色が少し暗くなる
- **所要時間**: 約0.1秒

### 4. カスタム画面から通常バトルへの復帰アニメーション

確定ボタンを押した後、通常バトル画面に戻るときのアニメーション。

#### アニメーション概要

- **カスタム画面全体の非表示**: 画面内から画面外へスライド（画面外に移動する前に一瞬右へ移動しポップな印象を付ける）
- **カスタムゲージの復帰**: 文字がフェードアウトし、ゲージが最大から0に向かって急速にアニメーション

## インタラクション仕様

**注意**: この章はUI/UXの視覚的な振る舞いのみを記載しています。コスト計算やシリーズボーナスなどのゲームロジックは `Planning/バトルシステムについて` を参照してください。

### カード選択のルール（ビジュアル面）

#### 選択可能枚数の表示
```
最小: 0枚
最大: 5枚
※ただし、実際の選択可能性はコスト制限など他の要因にも依存します（詳細はバトルシステム仕様参照）
```

#### 選択可能な状態（視覚表現）
- カスタム画面が表示されている
- カードが通常の色で表示されている
- クリック可能な状態

#### 選択不可能な状態（視覚表現）
- カードがグレーアウト表示
- 半透明表示
- カーソルホバー時に変化なし

#### 選択状態の確認
- 確定ボタンの上にアイコンを5つ用意し、選択している数だけ点灯、選択していない数はグレーアウト

### 確定ボタンの有効化条件

```
有効:
  - 1枚以上のカードが選択されている
  - アニメーション中でない

無効:
  - カードが1枚も選択されていない
  - アニメーション実行中
```

### キーボード操作（オプション）

将来的にキーボード操作を実装する場合:

- **矢印キー**: カードフォーカス移動
- **スペースキー**: カード選択/解除
- **Enterキー**: 確定ボタン押下
- **Escapeキー**: キャンセル（未選択状態に戻す）

## エフェクト・演出

### カスタムゲージ満タン時の演出

カスタムゲージが100%に到達したとき:

#### パルスエフェクト
- ゲージ色がゴールドに変化
- 拡大縮小を繰り返す（0.5秒周期）
- 白いハイライトが流れる

#### サウンドエフェクト
- 「ピピピピッ！」または「シャキーン！」
- やや大きめの音量
- プレイヤーに注目を集める

#### 画面シェイク（オプション）
- 画面がわずかに振動

### カスタム画面表示中の背景演出

カスタム画面が表示されている間:

#### 背景のバトルフィールド
- 変化なし

#### パーティクルエフェクト（オプション）
- なし

### 確定時のエフェクト

「確定」ボタンを押したとき:

#### フラッシュエフェクト
- 画面全体が一瞬白くフラッシュ

#### サウンドエフェクト
- 決定SEと確定ボタンに軽いエフェクト

#### 選択カードの強調
- なし

## レスポンシブ対応

### 画面解像度別の調整

#### 基本解像度（1920x1080）
- カスタムパネル、カード、ボタンは標準サイズ

#### 縦長の解像度比率
- カスタム画面のパーツは上端下端に左右されない

#### 横長の解像度比率
- カスタム画面のパーツは画面左端に追従

### タッチ操作対応

#### カードのタッチエリア
- 最小サイズ48px以上を確保
- タッチ判定をカードの外側まで拡張

#### 確定ボタンのタッチエリア
- 最低でも48px高さを確保
- 周囲に十分な余白を設ける

---

## アクセシビリティ

### 色覚異常対応

#### 選択状態の表現
- 色の変化だけでなく、チェックマークで視覚的に明示
- 枠線の太さを変える

#### 確定ボタンの状態
- 色だけでなく、アイコンで有効/無効を示す

### サウンド以外のフィードバック

#### ゲージ満タン時
- 視覚的な演出（パルス、色変化）を強調
- 画面シェイクで触覚的なフィードバック（オプション）

#### カード選択時
- チェックマークの表示
- スケール変化で明確に選択状態を示す

## デザインチェックリスト

カスタム画面実装時、以下を確認してください:

- [ ] カスタムゲージ満タン時の演出が実装されているか
- [ ] HPゲージとカスタムゲージのアニメーションが滑らかか
- [ ] カスタムパネルの表示アニメーションが0.7秒以内に完了するか
- [ ] カード選択時のフィードバック（色変化、チェックマーク）が明確か
- [ ] 確定ボタンの有効/無効状態が視覚的にわかりやすいか
- [ ] 復帰アニメーションが0.6秒以内に完了するか
- [ ] オーバーレイの不透明度が適切か（0.7推奨）
- [ ] カードのタッチエリアが48x48px以上確保されているか
- [ ] 色覚異常でも選択状態が判別可能か
- [ ] レスポンシブ対応がされているか（1280x1080以上）

## 今後の拡張案

### Phase 2（将来実装予定）

- **カスタムゲージの複数段階**: ゲージが複数段階あり、段階ごとに異なる演出
