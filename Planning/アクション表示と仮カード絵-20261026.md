# アクション表示と仮カード絵（2026-10-26）

## 実装範囲

既存の CardEffectFactory/ICardEffect/IAsyncCardEffect に接続する CardActionSequenceEffect を追加した。カードに固定せず、列内の各 CardActionDefinition が単体効果、既存 PlayerAttackTiming、共有可能な ActionVisualDefinition を参照する。複数カードから同一定義/素材を共有でき、同一素材でも別のフレーム設定を入力できる。同素材の設定値は基本揃えるという登録方針であり、構造上の強制ではない。

表示は BattleSystem の停止対象アクション時計を参照し、独立した壁時計やアニメ用待機を作らない。前後隙の配分は既存性能と一致することを検証し、不一致を拒否する。実際の単体効果の発生をマークし、発生マーカーとの一致を診断できる。飛翔体/派生効果は既存寿命のまま、本体の後隙とは分離する。派生待機は必要なアクションへ明示指定する。旧カード全体の派生延長指定を暗黙には移行しない。

ActionPoseRenderer と GameFieldView の明示登録入口は、本体 Sprite と別子ノードの武器 Sprite を切り替える。コマごとの握り位置を設定し、剣→銃切替/終了/取消/非表示時には古い武器を消し、元 Sprite/Animator 有効状態を復元する。キャラクター Transform の回転/倍率を変更しない。未登録素材を別モーションで代用しない。

## 製品登録と素材の境界

既存製品の発生/硬直時間、カード性能、保存 DTO、Scene/Prefab を変更していない。非0時間の仮登録について回答待ちのため、明示的な検証用設定だけで列・表示経路を確認する。製品の攻撃モーションが完成したという意味ではない。

ソードの予備動作は生成済みの1コマだけで、まだ製品登録していない。振り抜き生成は画像サービスの出力安全判定で拒否された（request 3bd9c27a-e1c7-459f-9c88-b9d5e60494d0）。同操作は再試行していない。振り抜き/復帰、投擲、ショットの専用連番、および製品用の差替武器素材が不足する。本節公開時点ではProjectileKeyは表示参照情報までだった。後続の[飛翔体素材接続](飛翔体素材接続-20261026.md)で機構を接続したが、製品の専用素材は未登録。既存 Bomb 等の描画と寿命は維持する。

## 仮カード本絵

Resources/OlcaCards の既存仮素材6種（sword/fire_sword/bomb/heal/shield/tuning）を、明快な輪郭・少数段階の影・装飾/光/質感を抑えたフラットなアニメ塗りへ差し替えた。未設定だった fire/ice も専用の正方形非ドット絵を追加した。全8枚とも OpenAI 画像生成ツールで新規作成した仮素材で、ミニアイコンの拡大ではない。ユーザー正式素材・背景・JikiTourai は変更しない。

fire/ice は現データでは無属性のソード系フォールバックであり、名称から炎/氷の能力を作らず、赤/青の柄を持つ通常の剣として描いた。同じ heal/shield ID でもフォールバックが攻撃カードの場合はソード絵/ミニアイコンを使い、製品の回復/防御定義では各専用絵を使う。明示 CardVisualEntry の正式登録は最優先する。
