# 敵の行動システム仕様書

> 2026-10-18追記: [ゲーム全体仕様](ゲーム全体仕様.md)第7・8節の強靭度・のけぞり・無敵・状態異常耐性を敵味方共通で適用する。競合する古いルールは新仕様を優先する。

## 1. 基本原則

### 1.1. コンセプト
敵のAI行動は**リアルタイム**で実行され、プレイヤーとは独立して動作します。各敵は**行動パターン（シーケンス）**に従い、決められた順序で移動・攻撃・特殊行動を実行します。

### 1.2. 設計方針
- **行動パターン制**: 敵は複数の行動パターンを持ち、順番に実行する
- **カード効果ベースの攻撃**: 攻撃行動はカード効果システムを利用して定義
- **HP閾値でパターン切り替え**: HP割合に応じて使用する行動パターンを変更可能
- **クールダウン管理**: 各行動は実行後にクールダウン時間を持つ
- **プレイヤーの座標判定**: 敵はプレイヤーの**ヒット判定用座標**を狙う
  - 一時移動カードにより、移動可否判断用の座標とヒット判定用の座標が異なる場合がある
  - 距離計算や攻撃対象の判定には常にヒット判定用座標を使用する

---

## 2. 移動行動の種類

敵の移動行動は以下の種類を組み合わせて行動パターンに組み込みます。

### 2.1. 移動しない（Stay）
初期位置から移動せず、プレイヤーが接近するのを待つ。

### 2.2. ランダム移動（Random Move）
フィールド内をランダムに移動する。移動可能なマスの中からランダムに1マス選択して移動。

### 2.3. プレイヤーに接近（Approach Player）
プレイヤーに1マス近づく移動。隣接している場合は移動しない。

### 2.4. プレイヤーから後退（Retreat from Player）
プレイヤーから1マス遠ざかる移動。フィールド端の場合は移動しない。

### 2.5. 距離維持（Keep Distance）
プレイヤーとの理想距離を維持する移動。近すぎたら後退、遠すぎたら接近。

### 2.6. 一時移動（Temporary Move）
一時的に別の座標に移動し、行動後に元の位置に戻る。攻撃と組み合わせて使用

---

## 3. 攻撃行動（カード効果ベース）

敵の攻撃行動は**カード効果システム**を利用して定義します。攻撃内容はカードIDで指定し、既存のカード効果ロジックを再利用します。

### 3.1. カード効果を使用した攻撃
敵は攻撃行動として「カードを使用する」という形で攻撃を実行します。

**仕組み**:
- 敵の行動パターンに「攻撃行動」を定義
- 攻撃行動にはカードIDを指定
- 実行時に指定されたカード効果を発動（ダメージ、デバフ、パネル変更など）

**利点**:
- プレイヤーとカード効果ロジックを共有できる
- 新しいカード効果を作れば、自動的に敵も使用可能
- 攻撃内容の定義が一元化される

### 3.2. 攻撃の種類（カード効果の例）
敵が使用できる攻撃カードの種類：

- **近接攻撃カード**: 隣接マスの相手にダメージ
- **遠距離攻撃カード**: 指定距離の相手にダメージ
- **範囲攻撃カード**: 複数マスを同時攻撃
- **貫通攻撃カード**: 直線上の全マスを攻撃
- **属性攻撃カード**: 属性ダメージ＋追加効果
- **デバフ攻撃カード**: ダメージ＋デバフ付与
- **パネル操作攻撃カード**: ダメージ＋パネル変更

### 3.3. 一時移動＋攻撃の組み合わせ
敵は「一時移動」と「攻撃」を組み合わせることで、特殊な攻撃パターンを実現できます。

**例**:
- 一時移動でプレイヤーの背後に回り込む → 背後から攻撃 → 元の位置に戻る
- 一時移動で距離を詰める → 近接攻撃 → 元の位置に戻る

## 4. 行動パターンシステム

### 2026-10-25 ユーザー確定の実行・切替境界

- 現在の行動を実行できない場合は、次の行動へ進む。全行動が実行不可でも同じ更新内で無限に再走査しない。
- 行動パターンの切替は、現在実行中の行動が完了してから行う。実行中の行動を切替だけで途中キャンセルしない。
- 切替後は新AI側の定義済み行動列の待ち時間だけを使い、旧AIの残りクールダウンを引き継がない。別の切替待ちを追加せず、二重に待たせない。
- 既存の通常AIは同期Executeで行動が完了し、その後に各EnemyAIBehaviorがGetCooldownMsの待ち時間を所有する。同じ行動列内の順次実行/実行不可skipは既存時計を維持し、行動列を切り替えるときだけ旧待ちを破棄する。現在の登録リストは従来どおり繰り返し利用し、製品patternのloop/停止/次patternの登録は別単位。


### 4.1. 行動パターンとは
敵は**行動パターン（Action Pattern）**という単位で行動を定義します。行動パターンは複数の行動をシーケンスとして保持し、順番に実行します。

**行動パターンの構成要素**:
- **行動シーケンス**: 実行する行動のリスト（移動、攻撃、待機など）
- **ループ設定**: パターンの最後まで到達したらどうするか（ループ、停止、次のパターンへ）
- **クールダウン**: 各行動のクールダウン時間

**行動パターンの例**:
```
パターンA: [ランダム移動 → ランダム移動 → 一時移動＋攻撃（カードID: 101）]（ループ）
パターンB: [ランダム移動 → 攻撃（カードID: 102） → 攻撃（カードID: 103）]（ループ）
```

### 4.2. 行動の種類
行動パターンに組み込める行動の種類：

- **移動行動**: 移動しない、ランダム移動、接近、後退、距離維持、一時移動
- **攻撃行動**: カードIDを指定して攻撃（カード効果システムを使用）
- **待機行動**: 指定時間待機（演出用、タイミング調整用）
- **特殊行動**: バフ付与、デバフ付与、回復、召喚など（カード効果として定義）

### 4.3. 強靭度システム
強靭度システムの詳細は[バトルシステムについて - Section 5.3](バトルシステムについて#53-強靭度システム)を参照してください。

敵の強靭度パラメータについては、Section 6.1で定義されています。

### 4.4. パターン切り替えシステム
敵は複数の行動パターンを持ち、特定の条件で使用するパターンを切り替えることができます。

#### 4.4.1. HP閾値によるパターン切り替え
敵のHP割合に応じて行動パターンを変更します。

**例**:
- HP 100～50%: パターンA（近接攻撃中心）
- HP 50～0%: パターンB（遠距離攻撃＋召喚）

#### 4.4.2. カード効果によるパターン切り替え
敵がカード効果を使用したことをトリガーに、行動パターンを切り替えます。

**例**:
- 「強化カード」を使用した直後 → 攻撃的なパターンCに切り替え
- 「回復カード」を使用した直後 → 防御的なパターンDに切り替え

#### 4.4.3. 特殊条件によるパターン切り替え
特定の条件を満たしたときに行動パターンを変更します。

**条件の例**:
- **特定属性のダメージを受けた**: 火属性ダメージを受けた → 水属性攻撃パターンに切り替え
- **プレイヤーが特定行動を実行**: プレイヤーがバフカードを使用 → デバフ攻撃パターンに切り替え
- **時間経過**: バトル開始から30秒経過 → 強化パターンに切り替え
- **特定回数攻撃を受けた**: 3回攻撃を受けた → 防御パターンに切り替え
- **特定の敵が倒された**: 仲間の敵が倒された → 怒り状態パターンに切り替え

## 5. 敵の種類とサンプルパターン

### 5.1. 基本近接型（スライム）
**行動パターン**: 単一パターン
```
パターン1: [移動しない → 攻撃（近接攻撃カード）]（ループ）
```

**特徴**:
- 最もシンプルな敵
- 移動せず、プレイヤーが接近したら攻撃

---

### 5.2. アグレッシブ近接型（ゴブリン）
**行動パターン**: 単一パターン
```
パターン1: [プレイヤーに接近 → プレイヤーに接近 → 攻撃（近接攻撃カード）]（ループ）
```

**特徴**:
- プレイヤーに積極的に接近
- 隣接したら攻撃

---

### 5.3. 遠距離型（アーチャー）
**行動パターン**: 単一パターン
```
パターン1: [距離維持（理想距離: 2-3マス） → 攻撃（遠距離攻撃カード）]（ループ）
```

**特徴**:
- プレイヤーとの距離を維持
- 理想距離内で遠距離攻撃

---

### 5.4. 魔法攻撃型（メイジ）
**行動パターン**: HP閾値で切り替え
```
パターン1（HP 100～30%）: [移動しない → 攻撃（範囲攻撃カード） → 攻撃（デバフ攻撃カード）]（ループ）
パターン2（HP 30～0%）: [後退 → 攻撃（全体攻撃カード） → 攻撃（防御カード）]（ループ）
```

**特徴**:
- HP低下で行動パターンが変化
- 範囲攻撃とデバフを使用

---

### 5.5. サポート型（ヒーラー）
**行動パターン**: HP閾値で切り替え
```
パターン1（HP 100～50%）: [ランダム移動 → 攻撃（デバフ攻撃カード）]（ループ）
パターン2（HP 50～0%）: [後退 → 攻撃（回復カード） → 後退]（ループ）
```

**特徴**:
- HP低下で逃走＋回復
- サポート役として機能

---

### 5.6. 複雑なパターン型（ボス）
**行動パターン**: HP閾値＋特殊条件で切り替え
```
パターン1（HP 100～70%）: [ランダム移動 → ランダム移動 → 一時移動＋攻撃（近接攻撃カード）]（ループ）
パターン2（HP 70～30%）: [ランダム移動 → 攻撃（範囲攻撃カード） → 攻撃（遠距離攻撃カード）]（ループ）
パターン3（HP 30～0%）: [攻撃（召喚カード） → 攻撃（全体攻撃カード） → 攻撃（バフカード） → 攻撃（強力攻撃カード）]（ループ）

【パターン切り替え条件】
- プレイヤーが火属性攻撃を使用 → パターン2に強制切り替え
- 3回攻撃を受けた → パターン3に強制切り替え（防御無視）
```

**特徴**:
- 複数フェーズを持つ
- HP閾値と特殊条件で複雑な行動変化
- ボス戦らしい演出と戦略性

## 6. パラメータ設計

### 6.1. 敵自体のパラメータ
敵キャラクター自体が持つ基本パラメータ：

- **敵ID**（整数）: 敵の種類を識別するID
- **敵名**（文字列）: 敵の名前（例: "スライム", "ゴブリン"）
- **初期HP**（整数）: バトル開始時のHP（デフォルト: 100）
- **防御属性**（列挙型）: 敵が持つ防御属性（火耐性、水耐性、風耐性、土耐性、無属性）
  - 対応する属性攻撃を受けた場合、ダメージが軽減される
  - 例: 火耐性を持つ敵は火属性攻撃のダメージを50%軽減
- **強靭度**（整数）: 行動キャンセルに必要な累計ダメージ量（デフォルト: 30）
  - 行動中に受けた累計ダメージがこの値を超えると、現在の行動がキャンセルされる
  - 行動完了後、または行動キャンセル後に累計ダメージはリセットされる
  - 強靭度が高い敵ほど行動を妨害しにくい

### 6.2. 行動パターンのパラメータ
行動パターン全体に関するパラメータ：

- **パターンID**（整数）: 行動パターンの識別子
- **パターン名**（文字列）: 行動パターンの名前（例: "通常攻撃パターン"）
- **ループ設定**（真偽値）: パターン終了後に最初に戻るか（デフォルト: true）

### 6.3. 個別行動のパラメータ
行動パターン内の各行動に関するパラメータ：

- **行動タイプ**（列挙型）: 移動、攻撃、待機のいずれか
- **クールダウン時間**（秒数）: 行動後の待機時間（デフォルト: 1.0秒）
- **移動タイプ**（列挙型）: 移動行動の場合の移動方法（移動しない、ランダム、接近、後退、距離維持、一時移動）
- **カードID**（整数）: 攻撃行動の場合に使用するカードID
- **理想距離**（マス数）: 距離維持移動の場合の目標距離（デフォルト: 2）
- **一時移動先座標**（座標）: 一時移動の場合の移動先（相対座標または絶対座標）

### 6.4. パターン切り替え条件のパラメータ
行動パターンを切り替える条件のパラメータ：

- **条件タイプ**（列挙型）: HP閾値、カード効果使用、特殊条件のいずれか
- **HP閾値**（割合）: HP閾値条件の場合のHP割合（0.0～1.0）
- **トリガーカードID**（整数）: カード効果使用条件の場合のカードID
- **特殊条件タイプ**（列挙型）: 特定属性ダメージ受領、プレイヤー行動検知、時間経過、攻撃回数、敵撃破など
- **属性タイプ**（列挙型）: 特定属性ダメージ条件の場合の属性（火、水、風、土）
- **経過時間**（秒数）: 時間経過条件の場合の秒数
- **攻撃回数**（整数）: 攻撃回数条件の場合の回数
- **切り替え先パターンID**（整数）: 条件成立時に切り替える行動パターンID

### 現在の接続範囲

`BattleSystem.TrySwitchEnemyActionPattern`で登録済み・戦闘中の敵へ定義済み行動列を渡す。同期Execute中、または継続行動のIsRunning中なら完了まで保留して切替、既に行動後の待ち中なら行動は完了しているため旧待ちを破棄し、次の更新から新行動列を使う。同じ更新で旧/新の2行動を連続実行しない。停止中の切替要求でもpause/暗転/hitstopを解除せず、停止中に次の行動を実行しない。新しい待ち値を生成せず、新行動が持つGetCooldownMsだけを使う。

同じ同期行動中の複数の切替要求は、追加要求をfalseで拒否する。未指定の複数HP閾値の優先・競合解決を新設しない。具体的な製品HP閾値/行動列、loop/停止/次patternの製品設定、継続行動の寿命は下記の任意interfaceで接続し、具体的な敵カード/一時移動行動や予告前隙は未登録。同期/継続APIへの切替基盤を、全製品AI完成とはしない。


### 継続行動の寿命接続（2026-10-25）

時間を持つ行動は任意の`IContinuingEnemyAIAction`を実装し、Executeで開始、IsRunningで実行中、Tickで停止していない論理更新、Cancelで中断/終了の予約や一時状態を解放する。論理更新は固定1frameの通知として扱い、描画アニメーションの完了やTask.Delayでゲームを進めない。期間/効果は行動側の外部定義で、エンジンが製品のframeを作らない。既存同期行動は従来どおり。

継続行動の実行中は次行動を開始せず、切替要求を完了まで保持する。完了した更新で次行動を重ねて実行しない。通常完了ならその行動の待ち、切替があれば旧待ちを破棄して新列の待ちだけ使う。のけぞり/麻痺の中断、死亡/戦闘終了/離脱でCancelを一度だけ呼び、解除済み/破棄後にTickしない。EnemyAISystemの登録解除時に購読も解放する。停止中のTickは従来のBattleSystemの停止分岐で抑止する。

これは共通の寿命契約であり、敵カードの対象側/発動者を接続済みという意味ではない。現BattleContextはPlayer=Battle.Player、Enemies=Battle.Enemies、前方はPlayer位置から+Xで、回復・防御等もプレイヤー起点。敵としてそのまま実行すると対象が逆になる。敵が使うカード範囲と攻撃向き/自身buff/連鎖・設置・一時移動の対象契約を照合する別単位として扱い、未指定の全カード対応を仮定しない。


### 使用者・対象とHP条件の接続（2026-10-25）

基本の攻撃相手と自己回復/防御の扱いは本書§3/§4.2から実装でき、新しいゲーム仕様の決定待ちではない。`EnemyCardAction`と`BattleContext.EnemySource/ForwardX`が敵使用時の対象を共有効果へ渡す。HP区間の自動監視は`BattleSystem.ConfigureEnemyHpPatterns`から通常の論理AI更新へ接続し、完了待ちと旧待ち破棄の確定規則を使用する。HP境界の包含は入力データで明示させ、製品値は生成しない。§5.1のスライム設定例は既存カードと待ち時間を渡すbuilderとして接続可能。通常の製品登録とサンプル/非保存fixtureの違い、未接続の一時移動/Support等は[暫定実装一覧](暫定実装一覧.md)の最新節に記録する。


### 一時移動・集中・予告の共通接続（2026-10-25）

敵自身の論理位置/一時被弾位置、集中の所有/消費、定義済み前隙中の固定対象マス予告を共有カード効果へ接続。中断/死亡/離脱時に一時位置と予告を解除し、重複予告は別所有者が残れば維持する。描画直前の再読取りで取消後の古い枠を残さない。具体カード・時間・移動量・製品行動列の登録と専用モーション素材は別で、共通機構の成功を全製品AI完成とはしない。詳細と検証は[暫定実装一覧](暫定実装一覧.md)の最新節。


### 通常移動とLoop/Stop/Nextの接続（2026-10-25）

§2.1〜2.5の通常移動はEnemyMovementActionへ、§4.1/§6.2の終了設定は整数IDのEnemyActionPatternへ接続。Loop以外を単なる値待ちとせず、Stop後の停止保持/明示再開・Nextの完了後切替・不可行動の有限スキップを実装。ID/理想距離/待ち/終了先の製品割当ては外部入力であり、通常シーンと保存の既定を変更しない。Nextも既存の完了切替規則を使い、旧待ちを持ち越さず別の待機を加えない。詳細と実装/製品設定の境界は[暫定実装一覧](暫定実装一覧.md)の最新節。
