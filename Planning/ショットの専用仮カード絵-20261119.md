# ショットの専用仮カード絵（Stage406）

基準 master `7db5055`。初期カードのうち Shot (`trial-shot-v1`) だけを対象に、左上の大きいカード絵をミニアイコンのフォールバックから専用イラストへ分離する。他の新カード3種、既存8枚、カードID・性能・タイミング・保存・入力・フォントは変更しない。

## 素材と接続

既存8枚を実読し、共通の青灰色背景・淡い菱形・輪郭の明瞭なアニメ塗りに合わせ、画像生成ツールで新規の1枚を制作した。題材は実際のミニアイコンと同じ右向きの青緑色の直進弾。元ミニの拡大・描き換えではない。1254×1254 PNG / RGB / 不透明 / 非ドットの仮素材であり、正式イラスト完成とは扱わない。

`Resources/OlcaCards/trial-shot-v1.png` を既存の Texture2D パス読込・Sprite生成・キャッシュ・解放へ接続する。明示 `CardVisualEntry.Illustration` の優先は維持。ミニは既存 `TrialInitialMiniIcon` の256×256・Point表示を維持する。登録は[既存の仮カード絵](仮カードイラスト-20261025.md)と同じPNG公開方式で、GUIDをSceneへ追加せず、metaを手作業で生成・変更しない。

画像生成スキルは利用一覧・`.agents/skills` に存在しなかったが、標準 image_gen.imagegen が利用可能で、生成PNGのローカル保存・読込に成功した。参照は既存 sword / bomb / heal。本単位で拒否された生成の再試行・別経路への迂回はない。

## 通常Playerと反映判定

隔離した既存セーブを使い、通常の「つづきから」→探索→出撃確認→ダンジョン接敵→カスタムでShotを選択した。FHD1920×1080で左上の専用絵と従来の小矢印を確認。同セーブのコピーを実出力3840×2160へ再開し、通常操作で同じ選択を確認した。仮想X11出力の実4Kであり、物理4Kモニター・物理パッド・タッチの試験ではない。両Playerは正常終了0。報酬でShotが提示される通常経路の確認は未実施で、カスタムの確認から推定しない。

既存Prefabの画像枠は論理280×280だが、既存UIの全体縮尺により実画面の絵はFHD約220×220／4K約440×440となる。指定された実280／560pxは未達。画像自体は鮮明で切れ・歪み・重なりなしだが、サイズ要件の完了とは扱わない。他カードと共通レイアウトを保全する今回の1枚の範囲では、枠や共通縮尺は変更しない。

指定実寸が未達のため、候補4ファイルを未コミットで分離保全し、masterのcommit/pushは未実施。Libraryへの素材本体・比較画像の保存は、helperの接続失敗後、正規のネットワーク許可付き実行が自動安全審査で拒否された。ユーザー本人の明示的な共有許可が確認できないとの理由で、別経路で迂回していない。Library IDは未取得。

ビルド前に使用中でない旧Player400を整理し、現行Player401は維持。旧stage321ログは可逆圧縮して展開後SHA一致を確認し保全した。セーブ・素材・既存候補は保持する。


## Stage407 再確認と更新後の受入判断

前節はStage406時点の厳密な実寸解釈による保留履歴。追加指示で「既存絵と同枠・同等サイズ」を受入条件とし、共通UIの全体リサイズは今回に混ぜないことを確認した。元Stage406候補4ファイルと検証ハッシュは別ディレクトリにそのまま保全。製品CS2ファイル・PNGは同一のままで、今回の追加は本記録のみ。

実Prefabを使った計測では画像Rectは280×280、画像自身のscaleは1。`BattleView.RefreshCustomLayout`がカスタム全体を画面の半幅へ収めるため、共通containerScaleは0.78688530。FHDのCanvas倍率1で実220.3279px、実出力3840×2160のCanvas倍率2で440.6558pxとなる。280/560は縮小前の設計寸法であり、実描画280/560達成とは記載しない。Shotだけの縮小や登録不良ではなく、既存Bombも同じRect・1254×1254の画像として表示される。現行の共通縮尺を変える候補は今回作成しない。

Player406の隔離セーブでFHDと実4Kをそれぞれ通常起動・Continue・接敵し、同じカスタム内のBombとShotを比較撮影した。両方のサイズ・位置が一致し、切れ・歪み・重なりなし。ミニは従来の矢印のまま。物理4KモニターではなくX11実出力で、物理パッド・タッチは未確認。

FHDでは通常操作のShot使用と固有攻撃で敵を倒し、報酬プレビューまで到達した。ただし提示されたのは既存のフォールバック剣3枚で、Shotが通常抽選された映像とは扱わない。報酬関連の既存EditMode142/142成功に加え、隔離Editorで実CardReward Prefabへ製品Shotを渡し、`ConfigurePresentation`→`ShowAsync`→`CardSelectionItemView`の専用Sprite・正方形256枠・1枚表示・miniとの分離を検証して成功。DungeonBattleControllerの実resolver接続も照合した。これは自動経路検証であり、通常PlayerでShot報酬が提示された確認ではない。

製品ソース424パスはStage406全件6,332/6,332・関連9/9の検証済みハッシュから変更なし。追加確認後に保全・Console・独立レビュー・公開ゲートを照合して、合格したShot単独4ファイルだけを通常の製品反映対象とする。Library保存は別の承認待ちのままで再実行せず、製品反映をその代替にはしない。
