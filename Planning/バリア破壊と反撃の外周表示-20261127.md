# 二体戦のバリア破壊と反撃の表示（Stage 449）

## 対象と根拠

基準 master `1f28615442eb7b1f7903a673b9c788660ee5e187`。通常の任意出撃「シヨウ ユミ・ソード」の歩き接敵セーブを隔離コピーし、弓の予告回避後、スターター Shield を前衛の Sword に使って反撃する流れを確認した。

`ゲーム全体仕様.md` のバリアは破壊フレームの全攻撃を吸収し、超過分をHPへ通さない。防御成功・破壊には専用演出を設ける。Shield はガードではなく耐久15のバリアであり、ガードやオーラの新ルールは追加しない。

## 表示だけの変更

- バリア吸収通知から、HPフレーム確定後の残耐久を描画時に読む。
- 耐久が残れば小さい外周パルス、破壊なら6個の薄紫の破片が外へほどける。中央を塗らず、黄色い敵予告や通常被弾の赤白点滅と区別する。
- 18論理フレームの試用演出。カスタムとポーズでは同じ論理時刻を保持し、解除後は残期間だけ進む。移動の瞬間非表示では演出を終了せず、到着時に残期間を表示する。
- 戦闘終了、死亡、無効化、別セッションへの接続で解除。生成画像は自作の透明ダイヤ形で、一つの所有コンテナにまとめて破棄する。
- Core、入力、ダメージ・耐久・射程・攻撃時刻、敵AI、カード、セーブ、既存キャラ・予告・チャージ姿勢は変更しない。

## 通常Playerで確認したこと

Linux Desktop Player、1280×720、元のユーザーセーブは操作せず隔離コピー。

1. 同じ歩き接敵の二体、プレイヤー100、前衛50、弓60。Shield、Swordを選択。
2. 最初の弓の固定予告から左へ回避。HP100のままShieldを発動し、右へ二歩接近。
3. 前衛の30ダメージはバリアが吸収。HP100を維持してバリア表示・状態アイコンが消え、薄紫の破片が表示・消散する。
4. 続くSwordが前衛に命中し、50→20。弓は60のまま。通常攻撃や無敵状態を新設せず既存の反撃が成立。
5. その後の別操作で離脱した際は次の矢を受けHP90になった。反撃までの無傷区間と区別し、無条件の安全離脱とはしない。

旧版の比較は別テイクで初弾を受けたHP90の状態。そこでもバリア吸収と反撃中はHP90を維持した。比較動画はHP条件の違いを明記し、HP性能が改善した証拠とは扱わない。
