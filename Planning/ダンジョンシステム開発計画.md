# ダンジョンシステム開発計画

## 1. 概要

このドキュメントは、Olcaプロジェクトにおけるダンジョンシステムの段階的な実装計画を定めるものです。

### 目的
- 仕様書「[ダンジョンについて](ダンジョンについて)」に基づき、実装可能な形に落とし込む
- Unity非依存のCore層とUnity依存のPresentation層に分離したアーキテクチャで実装
- テスト駆動開発により、堅牢なロジックを構築

### 前提条件
- バトルシステムは実装済み
- Core層とPresentation層のアーキテクチャが確立済み
- 基本的なインターフェース（IRandomProvider等）が実装済み

## 2. アーキテクチャ方針

### 2.1. レイヤー構造

```
Core/Logic/Dungeon/        ← ダンジョンロジック（Unity非依存）
  ├── DungeonSystem.cs          # ダンジョン進行管理
  ├── DungeonMap.cs             # マップ構造とマス管理
  ├── PlayerMovement.cs         # プレイヤー移動ロジック
  ├── ContactSystem.cs          # 接敵判定システム
  ├── ActionSystem.cs           # ダッシュ・ジャンプのロジック
  └── CardRewardSystem.cs       # カード獲得・選択ロジック

Core/Logic/Integration/    ← ダンジョン+バトル統合ロジック
  └── DungeonBattleManager.cs   # ダンジョン・バトル間の状態管理

Core/Domain/               ← ドメインモデル
  ├── DungeonConfig.cs          # ダンジョン設定データ
  ├── MapCell.cs                # マスのデータ
  ├── Obstacle.cs               # 障害物データ
  └── DungeonEnemy.cs           # ダンジョン内の敵データ

Presentation/Field/        ← ダンジョン・バトルを統合したWorld Spaceビュー
  ├── GameFieldView.cs          # フィールド全体の表示管理（カメラ追従含む）
  ├── WorldEnemyView.cs         # ワールド上の敵スプライト表示
  └── WorldBattleGridView.cs    # バトルグリッドのオーバーレイ表示

Presentation/Dungeon/      ← 接敵アニメーション
  └── ContactAnimator.cs        # 通常/ダッシュ接敵アニメーション（UniTask）

Application/Dungeon/       ← Controller層
  └── DungeonBattleController.cs  # ロジックとビューの仲介（ダンジョン+バトル一体）
```

> **設計変更の経緯（2026-03-24）**
> 当初は `DungeonView` + `BattleFieldView` を別々のCanvasとして切り替える設計を予定していたが、
> ワールドスペースでのシームレス遷移を実現するため、`Presentation/Field/` に統合した。
> ダンジョンでの敵スプライトとバトルグリッドを同一シーン内で共存させ、
> カメラ移動でフェーズを切り替える方式を採用。

### 2.2. 設計原則

1. **ロジックと表示の完全分離**
   - Core層は一切Unityに依存しない
   - `deltaTime`は外部から受け取る
   - 位置情報は数値で管理（座標はView層で変換）

2. **Coroutine禁止**
   - 移動・アニメーションは`Update(deltaTime)`で更新
   - 将来的にUniTaskで非同期処理

3. **イベント駆動**
   - 状態変化時にイベントを発火
   - View層がイベントを購読して表示更新

```csharp
// DungeonSystem.cs - ダンジョン全体管理
public class DungeonSystem
{
    private readonly DungeonMap map;
    private readonly PlayerMovement playerMovement;
    private readonly ContactSystem contactSystem;
    private readonly ActionSystem actionSystem;
    private readonly Deck currentDeck;  // 攻略中のデッキ

    public DungeonSystem(DungeonConfig config, Deck initialDeck, IRandomProvider random)
    {
        map = new DungeonMap(config);
        playerMovement = new PlayerMovement(map);
        contactSystem = new ContactSystem(map);
        actionSystem = new ActionSystem();
        currentDeck = new Deck(initialDeck); // コピーを作成
    }

    // 毎フレーム更新（deltaTimeを外部から受け取る）
    public void Tick(float deltaTime)
    {
        if (IsInBattle) return;  // バトル中は更新しない

        playerMovement.Update(deltaTime);
        contactSystem.CheckContact(playerMovement.CurrentPosition);
    }

    public bool IsInBattle { get; private set; }
    public bool IsDungeonCleared { get; private set; }

    // イベント
    public event Action<Enemy> OnBattleStart;
    public event Action OnBattleEnd;
    public event Action<List<Card>> OnCardRewardOffered;
    public event Action OnDungeonClear;
}

// PlayerMovement.cs - プレイヤー移動ロジック
public class PlayerMovement
{
    private float currentPosition;  // 現在位置（浮動小数点）
    private float velocity;         // 速度
    private bool isJumping;
    private bool isDashing;

    private const float BASE_SPEED = 2.0f;      // 基本移動速度（マス/秒）
    private const float DASH_SPEED = 5.0f;      // ダッシュ速度
    private const float JUMP_DURATION = 0.5f;   // ジャンプ時間

    public float CurrentPosition => currentPosition;
    public float Height { get; private set; }  // 高さ（0.0=地上）
    public bool IsDashing => isDashing;

    public void Update(float deltaTime)
    {
        // 速度決定
        float speed = isDashing ? DASH_SPEED : BASE_SPEED;
        currentPosition += speed * deltaTime;

        // ジャンプ処理
        if (isJumping)
        {
            UpdateJump(deltaTime);
        }
    }

    public void StartDash()
    {
        isDashing = true;
    }

    public void StopDash()
    {
        isDashing = false;
    }

    public void Jump()
    {
        if (isJumping) return;
        isJumping = true;
        jumpTimer = 0f;
    }

    private float jumpTimer;
    private void UpdateJump(float deltaTime)
    {
        jumpTimer += deltaTime;
        // 放物線運動（簡易実装）
        Height = Mathf.Max(0f, Mathf.Sin((jumpTimer / JUMP_DURATION) * Mathf.PI));

        if (jumpTimer >= JUMP_DURATION)
        {
            isJumping = false;
            Height = 0f;
        }
    }
}

// ContactSystem.cs - 接敵判定システム
public class ContactSystem
{
    private readonly DungeonMap map;
    private const float CONTACT_DISTANCE = 1.0f;      // 非ダッシュ時の停止距離（敵に隣接）
    private const float DASH_CONTACT_DISTANCE = 1.5f; // ダッシュ時の接敵距離（通り抜け防止のため少し長め）

    public ContactSystem(DungeonMap map)
    {
        this.map = map;
    }

    public void CheckContact(float playerPosition)
    {
        MapCell nextCell = map.GetCellAtPosition(playerPosition + CONTACT_DISTANCE);

        if (nextCell != null && nextCell.Type == CellType.Enemy)
        {
            OnEnemyContact?.Invoke(nextCell.Enemy);
        }
    }

    public event Action<Enemy> OnEnemyContact;
}
```

```csharp
// ActionSystem.cs - アクション管理
public class ActionSystem
{
    public bool CanDash { get; private set; } = true;
    public bool CanJump { get; private set; } = true;

    // ダッシュ効果の種類
    public enum DashContactEffect
    {
        InitialDamage,  // 初期ダメージ
        Stun,           // スタン
        FirstStrike     // 先制攻撃
    }

    // ダッシュ接敵時の効果を取得
    public DashContactEffect GetDashEffect()
    {
        // TODO: キャラクター能力に応じて変更
        return DashContactEffect.InitialDamage;
    }

    // ジャンプで回避可能かチェック
    public bool CanAvoidWithJump(MapCell cell, float playerHeight)
    {
        if (cell.Type == CellType.Boss)
            return false;  // ボスは回避不可

        // 地上の敵は一定の高さ以上でジャンプすれば回避可能
        if (cell.Type == CellType.Enemy && cell.Height == 0f)
        {
            return playerHeight > 0.5f;
        }

        // 空中の敵は高さが足りなければ回避不可
        if (cell.Type == CellType.Enemy && cell.Height > 0f)
        {
            return playerHeight >= cell.Height - 0.2f;
        }

        return false;
    }
}
```

```csharp
// CardRewardSystem.cs - カード報酬管理
public class CardRewardSystem
{
    private readonly Deck dungeonDeck;  // 攻略中のデッキ
    private readonly IRandomProvider random;
    private readonly List<Card> obtainedCards;  // 入手したカード

    private const int REWARD_CHOICE_COUNT = 3;  // 選択肢の枚数

    public CardRewardSystem(Deck initialDeck, IRandomProvider random)
    {
        dungeonDeck = new Deck(initialDeck);
        this.random = random;
        obtainedCards = new List<Card>();
    }

    // カードドロップ判定
    public bool ShouldDropCard(Enemy defeatedEnemy)
    {
        // 50〜70%の確率でドロップ
        float dropRate = defeatedEnemy.IsBoss ? 1.0f : 0.6f;
        return random.Range(0f, 1f) < dropRate;
    }

    // カード選択肢を生成
    public List<Card> GenerateCardChoices(Enemy defeatedEnemy)
    {
        List<Card> choices = new List<Card>();

        // ボスの場合は1枚のみ
        int choiceCount = defeatedEnemy.IsBoss ? 1 : REWARD_CHOICE_COUNT;

        for (int i = 0; i < choiceCount; i++)
        {
            Card card = GenerateRandomCard(defeatedEnemy);
            choices.Add(card);
        }

        return choices;
    }

    // カードを選択してデッキに追加
    public void SelectCard(Card selectedCard)
    {
        dungeonDeck.AddCard(selectedCard);
        obtainedCards.Add(selectedCard);
        OnCardAdded?.Invoke(selectedCard);
    }

    // ダンジョン攻略中のデッキを取得
    public Deck GetCurrentDeck() => dungeonDeck;

    // 入手したカードのリスト（クリア報酬用）
    public IReadOnlyList<Card> ObtainedCards => obtainedCards;

    public event Action<Card> OnCardAdded;

    private Card GenerateRandomCard(Enemy enemy)
```

```csharp
// ObstacleSystem.cs - 障害物管理
public class ObstacleSystem
{
    private readonly DungeonMap map;

    public void CheckCollision(PlayerMovement player)
    {
        MapCell currentCell = map.GetCellAtPosition(player.CurrentPosition);

        if (currentCell?.Type == CellType.Obstacle)
        {
            // 高さが足りない場合は衝突
            if (player.Height < currentCell.Height)
            {
                ApplyPenalty(currentCell.Obstacle);
                OnObstacleHit?.Invoke(currentCell.Obstacle);
            }
        }
    }

    private void ApplyPenalty(Obstacle obstacle)
    {
        switch (obstacle.PenaltyType)
        {
            case ObstaclePenaltyType.ImmediateDamage:
                OnImmediateDamage?.Invoke(obstacle.PenaltyValue);
                break;

            case ObstaclePenaltyType.StatusEffect:
                OnStatusEffectApplied?.Invoke(obstacle.StatusEffectId);
                break;

            case ObstaclePenaltyType.CardDiscard:
                OnCardDiscard?.Invoke(obstacle.PenaltyValue);
                break;
        }
    }

    public event Action<Obstacle> OnObstacleHit;
    public event Action<int> OnImmediateDamage;
    public event Action<string> OnStatusEffectApplied;
    public event Action<int> OnCardDiscard;
}
```

### フェーズ5: バトルシステムとの統合（シームレス遷移）

**目標**: ダンジョンとバトルのシームレスな連携を実現する

このフェーズでは、ダンジョン探索からバトルへの**シームレスな移行**を実装します。
単なるシーン遷移ではなく、同一シーン内でダンジョンフェーズとバトルフェーズを切り替える設計とします。

---

#### 実装内容

##### 3.5.1. シームレス遷移の設計方針

**重要な設計原則:**
- **シーン分割しない**: ダンジョンとバトルは同一シーン内で共存
- **カメラワークで切り替え**: カメラの移動・ズームでフェーズを切り替える
- **状態管理を一元化**: `DungeonSystem`がバトルシステムを保持・管理
- **HP・デッキの連続性**: プレイヤー状態をシームレスに引き継ぐ

**シームレス遷移の流れ:**
```
[ダンジョンフェーズ]
    ↓ 敵と接敵
[接敵演出] ← ダッシュの場合は突進・吹き飛ばし演出
    ↓
[バトルフェーズ] ← カメラズームイン、グリッドにフォーカス
    ↓ バトル終了
[カード選択画面] ← 勝利時のみ
    ↓
[ダンジョンフェーズ] ← カメラズームアウト、スクロール再開
```

##### 3.5.2. Core層: DungeonSystem のバトル統合

```csharp
// DungeonSystem.cs - バトルシステムとの統合
public class DungeonSystem
{
    private readonly PlayerCharacter playerCharacter;
    private readonly DungeonMap map;
    private readonly PlayerMovement playerMovement;
    private readonly ContactSystem contactSystem;
    private readonly CardRewardSystem cardRewardSystem;

    // バトル管理
    private BattleSystem currentBattle;
    private ContactInfo currentContactInfo;  // 接敵情報を保持

    public bool IsInBattle { get; private set; }
    public BattleSystem CurrentBattle => currentBattle;

    // ========== バトル遷移 ==========

    /// <summary>
    /// 敵との接敵時にバトルを開始
    /// </summary>
    public void StartBattle(ContactInfo contactInfo)
    {
        IsInBattle = true;
        currentContactInfo = contactInfo;

        // ダンジョンの位置関係からバトルフィールドを生成
        BattleField field = CreateBattleFieldFromDungeon(contactInfo);

        // バトルシステムを初期化
        // 注意: プレイヤーのHPはダンジョン探索中のまま
        List<Enemy> enemies = GatherEnemiesForBattle(contactInfo);

        currentBattle = new BattleSystem(
            playerCharacter,  // HPなどの状態を引き継ぐ
            enemies,
            cardRewardSystem.GetCurrentDeck(),  // 攻略中のデッキを使用
            customGaugeSpeed: 2.0f,
            randomProvider,
            logger
        );

        // ダッシュ接敵の効果を適用
        if (contactInfo.IsDashContact && contactInfo.DashEffect.HasValue)
        {
            ApplyDashEffect(contactInfo.DashEffect.Value, enemies);
        }

        // バトル終了イベントを購読
        currentBattle.OnBattleEnd += OnBattleCompleted;

        OnBattleStart?.Invoke(contactInfo);
    }

    /// <summary>
    /// ダンジョンの位置関係からバトルフィールド（6x1グリッド）を生成
    /// </summary>
    private BattleField CreateBattleFieldFromDungeon(ContactInfo contactInfo)
    {
        BattleField field = new BattleField();

        // ダンジョンでの相対位置をバトルグリッドに変換
        // プレイヤーは左側（0〜2マス目）、敵は右側（3〜5マス目）に配置

        int playerGridX = 1;  // デフォルトは1マス目
        int enemyGridX = 4;   // デフォルトは4マス目

        // ダッシュ接敵の場合は位置を調整
        if (contactInfo.IsDashContact)
        {
            // ダッシュで突進 → プレイヤーは2マス目、敵は5マス目（吹き飛ばされた状態）
            playerGridX = 2;
            enemyGridX = 5;
        }

        playerCharacter.Position = new Vector2Int(playerGridX, 0);
        contactInfo.Enemy.Position = new Vector2Int(enemyGridX, 0);

        // TODO: パネルタイプの設定（ダンジョンの地形に応じて）
        // 例: 火山ダンジョンならMagmaパネルが多い、など

        return field;
    }

    /// <summary>
    /// 画面内の敵を集めてバトルに参加させる
    /// </summary>
    private List<Enemy> GatherEnemiesForBattle(ContactInfo contactInfo)
    {
        List<Enemy> enemies = new List<Enemy>();

        // 接敵した敵を追加
        enemies.Add(contactInfo.Enemy);

        // 画面内にいる他の敵も巻き込む（仕様より）
        List<Enemy> nearbyEnemies = map.GetEnemiesInRange(
            playerMovement.CurrentPosition,
            range: 10.0f  // 画面の範囲
        );

        foreach (var enemy in nearbyEnemies)
        {
            if (enemy != contactInfo.Enemy)
            {
                enemies.Add(enemy);
            }
        }

        return enemies;
    }

    /// <summary>
    /// ダッシュ接敵の効果をバトルに適用
    /// </summary>
    private void ApplyDashEffect(ActionSystem.DashContactEffect effect, List<Enemy> enemies)
    {
        switch (effect)
        {
            case ActionSystem.DashContactEffect.InitialDamage:
                // 全敵に初期ダメージ
                foreach (var enemy in enemies)
                {
                    int damage = 15;  // TODO: プレイヤー攻撃力に応じて調整
                    enemy.TakeDamage(damage);
                    logger.LogInfo($"{enemy.Name}に{damage}ダメージ！（ダッシュ接敵）");
                }
                break;

            case ActionSystem.DashContactEffect.Stun:
                // TODO: スタン効果の実装（BattleSystemに追加が必要）
                logger.LogInfo("敵をスタンさせた！（ダッシュ接敵）");
                break;

            case ActionSystem.DashContactEffect.FirstStrike:
                // TODO: 先制攻撃の実装
                logger.LogInfo("先制攻撃！（ダッシュ接敵）");
                break;
        }
    }

    /// <summary>
    /// バトル終了時の処理
    /// </summary>
    private void OnBattleCompleted(BattleResult result)
    {
        // バトル終了イベントを解除
        currentBattle.OnBattleEnd -= OnBattleCompleted;

        if (result == BattleResult.Victory)
        {
            // 勝利時: カードドロップ判定
            if (cardRewardSystem.ShouldDropCard(currentContactInfo.Enemy))
            {
                List<Card> choices = cardRewardSystem.GenerateCardChoices(currentContactInfo.Enemy);
                OnCardRewardOffered?.Invoke(choices);
                // カード選択が完了するまでダンジョンに戻らない
            }
            else
            {
                // ドロップなしの場合は即座にダンジョンに戻る
                ReturnToDungeon();
            }
        }
        else
        {
            // 敗北時: ゲームオーバー
            OnDungeonFailed?.Invoke();
        }

        OnBattleEnd?.Invoke(result);
    }

    /// <summary>
    /// カード選択完了後、ダンジョンに戻る
    /// </summary>
    public void OnCardSelectionCompleted()
    {
        ReturnToDungeon();
    }

    /// <summary>
    /// ダンジョンフェーズに戻る
    /// </summary>
    private void ReturnToDungeon()
    {
        IsInBattle = false;
        currentBattle = null;

        // HP回復なし（ダンジョンの特殊ルール）
        // プレイヤーHPはバトル終了時のまま維持

        // 倒した敵をマップから削除
        map.RemoveEnemy(currentContactInfo.Enemy);

        // プレイヤー移動を再開
        playerMovement.Resume();

        OnReturnToDungeon?.Invoke();
    }

    // ========== イベント ==========
    public event Action<ContactInfo> OnBattleStart;
    public event Action<BattleResult> OnBattleEnd;
    public event Action<List<Card>> OnCardRewardOffered;
    public event Action OnReturnToDungeon;
    public event Action OnDungeonFailed;
}
```

**Unityシーン構成（実装版 2026-03-24）:**

```
DungeonScene (単一シーン)
├── MainCamera (カメラ制御)
│   └── GameFieldView が追従制御（cameraFollowEnabled フラグで切り替え）
│
├── DungeonBattleController (MonoBehaviour / Application層)
│   └── DungeonBattleManager (Core Logic)
│
├── GameFieldView (MonoBehaviour / World Space)  ← ダンジョン・バトル共通
│   ├── PlayerSprite (SpriteRenderer)
│   ├── WorldEnemyView × N (SpriteRenderer)
│   └── WorldBattleGridView (バトル時のみ表示)
│
├── BattleView (Canvas) ← バトル中のみ表示
│   ├── CustomScreenContainer
│   └── BattleUI (HP・カード手札等)
│
└── CardSelectionView (Canvas) ← カード選択時のみ表示
```

**実装された設計の特徴:**
1. **World Spaceスプライト統合**: ダンジョンとバトルで同じ敵スプライト・プレイヤースプライトを使い続ける。DungeonViewとBattleFieldViewは廃止。
2. **カメラ追従方式**: ダンジョン中はプレイヤー位置 + オフセットをLerpで追従。バトル開始時は `battleCameraTargetX` に向けてスムーズに移動。
3. **バトルグリッドのオーバーレイ**: `WorldBattleGridView` がWorld SpaceにグリッドUIを重ねる。`originX = playerTransform.position.x - playerGridX` でプレイヤー位置を基点にグリッドを配置（プレイヤーワープなし）。
4. **非バトル敵の非表示**: バトル時、グリッド範囲外（GridPosition.X < 0 or >= 6）の敵は `hiddenForBattle` フラグで非表示。

**メリット:**
- シーンロード不要 → ロード時間なし
- ダンジョン→バトルの位置関係がそのまま視覚的に引き継がれる
- プレイヤー・敵スプライトの継続表示で自然なシームレス遷移

**デメリット:**
- カメラ制御が複雑（follow/locked の切り替え管理が必要）

### 9.2. アニメーション演出のTips

#### カメラワーク
```csharp
// ✅ 良い例: イージング関数を使用してスムーズに
private async UniTask MoveCameraAsync(Vector3 targetPos, float duration)
{
    Vector3 startPos = mainCamera.transform.position;
    float elapsed = 0f;

    while (elapsed < duration)
    {
        elapsed += Time.deltaTime;
        float t = elapsed / duration;

        // イージング: EaseOutCubic
        float eased = 1f - Mathf.Pow(1f - t, 3f);

        mainCamera.transform.position = Vector3.Lerp(startPos, targetPos, eased);
        await UniTask.Yield();
    }

    mainCamera.transform.position = targetPos;
}
```

#### 接敵演出のタイミング調整
```csharp
// ダッシュ接敵演出の推奨タイミング
private async UniTask PlayDashContactAnimationAsync(ContactInfo contactInfo)
{
    // 1. 加速演出 (0.3秒)
    await PlayAccelerationEffectAsync();

    // 2. 衝突瞬間 (0.05秒) ← ヒットストップ
    Time.timeScale = 0.1f;
    await UniTask.Delay(TimeSpan.FromSeconds(0.05f), ignoreTimeScale: true);
    Time.timeScale = 1.0f;

    // 3. 吹き飛ばし (0.2秒)
    await PlayKnockbackEffectAsync(contactInfo.Enemy);

    // 4. プレイヤー宙返り (0.3秒)
    await PlayBackflipEffectAsync();
}
```

### 9.5. よくある問題と解決策

#### 問題1: バトル終了後、ダンジョンに戻るとプレイヤーが元の位置に戻ってしまう

**原因**: PlayerMovementの位置をリセットしている

**解決策**:
```csharp
// ✅ 良い例: 位置を維持
private void ReturnToDungeon()
{
    IsInBattle = false;
    currentBattle = null;

    // 位置はリセットしない（そのまま）
    playerMovement.Resume();  // 移動を再開するだけ
}

// ❌ 悪い例
private void ReturnToDungeon()
{
    playerMovement.SetPosition(0);  // 最初に戻ってしまう
}
```

#### 問題2: カメラが急に動いて酔う

**原因**: イージングなしでカメラを移動

**解決策**:
```csharp
// ✅ 良い例: スムーズな移動
await MoveCameraAsync(targetPos, duration: 0.5f);  // イージングあり

// ❌ 悪い例
mainCamera.transform.position = targetPos;  // 瞬間移動
```

#### 問題3: バトルとダンジョンのInputが干渉する

**原因**: 両方のUpdateが同時に動いている

**解決策**:
```csharp
// ✅ 良い例: IsInBattleで分岐
private void Update()
{
    if (dungeonSystem.IsInBattle)
    {
        // バトル入力のみ
        dungeonSystem.CurrentBattle.Tick(Time.deltaTime, inputProvider);
    }
    else
    {
        // ダンジョン入力のみ
        dungeonSystem.Tick(Time.deltaTime);
        HandleDungeonInput();
    }
}
```

#### 問題4: HPがバトル後に戻ってしまう

**原因**: PlayerCharacterインスタンスが別々

**解決策**:
```csharp
// ✅ 良い例: 同じインスタンスを共有
private readonly PlayerCharacter playerCharacter;

public DungeonSystem(DungeonConfig config, PlayerCharacter player, ...)
{
    this.playerCharacter = player;  // 外部から受け取る
}

public void StartBattle(ContactInfo contactInfo)
{
    currentBattle = new BattleSystem(playerCharacter, ...);  // 同じ参照を渡す
}
```

### 9.6. パフォーマンス計測

#### 遷移時間の計測
```csharp
private async UniTaskVoid StartBattleTransitionAsync(ContactInfo contactInfo)
{
    var stopwatch = System.Diagnostics.Stopwatch.StartNew();

    await PlayContactAnimationAsync(contactInfo);
    Debug.Log($"接敵演出: {stopwatch.ElapsedMilliseconds}ms");

    stopwatch.Restart();
    await MoveCameraToBattleAsync();
    Debug.Log($"カメラ移動: {stopwatch.ElapsedMilliseconds}ms");

    stopwatch.Restart();
    // View切り替え
    dungeonView.gameObject.SetActive(false);
    battleView.gameObject.SetActive(true);
    Debug.Log($"View切り替え: {stopwatch.ElapsedMilliseconds}ms");

    stopwatch.Restart();
    battleView.Initialize(dungeonSystem.CurrentBattle);
    Debug.Log($"BattleView初期化: {stopwatch.ElapsedMilliseconds}ms");

    stopwatch.Stop();
}
```

**目標値:**
- 接敵演出: 300〜500ms
- カメラ移動: 500ms
- View切り替え: 16ms以内（1フレーム）
- BattleView初期化: 50ms以内
- **合計: 1秒以内**
