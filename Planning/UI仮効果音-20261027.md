# 自作UI仮効果音（2026-10-27）

## 対象と既存接続

基準master `352b4cc7ff9173ed742d47c4f98bdd1279bbf489`。前回の[音素材調査](音素材の自作手段調査-20261027.md)で確認した既存 `DungeonBattleController.MakeButton` のUI音再生先だけを対象にする。

- `press.wav`: 共通の操作音、80ms。
- `cancel.wav`: `CancelRetreat` / `CancelProgressAction` の明示的な取消/閉じる操作、96ms。
- `UiFeedbackSounds.ForButton` は既存の明示 `uiEffect` を最優先。未設定時だけ共有仮Clipを使う。新しい攻撃/被弾/変身の発音契機は追加しない。
- `GameplayAudioRouter` の全体×効果音音量、OneShot、ポーズ中の新規SE抑止、停止/破棄の既存動作を維持。ポーズ中の取消音まで鳴る仕様に変更していない。

## 制作と数値検証

外部素材・モデル・サービスを使わずPython標準 `wave/math/array` で合成。再現スクリプトは `Tools/Audio/create_placeholder_ui_sounds.py`。実行はリポジトリルートから `python3 Tools/Audio/create_placeholder_ui_sounds.py`。コマンドはこの2つの仮WAVだけを再生成するため、後から正式素材へ差し替えた後は用途を確認して実行する。

48,000Hz / 16bit / mono PCM、圧縮なし。波形は正弦波2成分にsin²窓を掛け、DCを窓内で除去、ピーク約0.100006（−19.9995dBFS）へ調整。両端サンプル0、先頭/末尾近傍もゼロ付近。pressは3,840サンプル、cancelは4,608サンプル。DC平均はそれぞれ約7.95e−9 / −5.30e−8。Python解析とFFprobe `pcm_s16le`/長さ/レート/チャンネルが一致。各音にクリップしたサンプルはなく、2音同時の理論振幅上限もフルゲインで約0.2。

## 聴感の制約

EditorログはALSA default出力が存在せず、`FMOD failed to initialize the output device` に続いて `FMOD initialized on nosound output` を記録している。`/dev/snd` / `/dev/dsp` もない。音声デバイス/OS/セキュリティ設定の変更はしていない。

したがって実スピーカー/ヘッドホンでの聴感・実機出力品質は未確認。Unityの再生API/寿命の確認と波形数値検証を、実際に聞いて品質合格した結果と混同しない。製品BGM・声・専用戦闘SEは今回の2音と別の残素材。
