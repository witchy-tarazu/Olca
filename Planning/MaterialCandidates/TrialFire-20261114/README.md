走行4姿勢は元と同尺度、共通の表示基準(127,17)/256で比較し、頭・胴・衣装・接地の静止画レビューは必須指摘0。姿勢ごとの拡縮で体格差を隠す処理はしていない。初期の4姿勢一括案と接地が浮いた個別案はこの保全対象に含めない。

次は01→03→05→07→01の連続再生、腰・頭の上下動、足滑り、前後の四肢を確認する。元Move8コマ／Idle10コマすべてに対応する完成連番ではない。ジャンプ頂点・下降、ダッシュ、壁ずり、地上／空中攻撃などの同衣装素材も不足しており、途中で通常衣装へ戻る状態のまま製品には接続しない。色のfringe、256px取込後の細線、実背景・Playerでの切替も未検証。

本体の通常攻撃素材とは別候補。探索空中前蹴りの通常衣装接触素材は別コミットで製品に接続済みである。既存の炎の識別レイヤーだけで本衣装の完成・実装済みとはしない。

manifest.jsonに原本寸法・アルファ範囲・生成ID・SHA256を記録した。検証コピーと元セーブ、既存戦闘の敵・数字フォントに変更はない。
