# 探索試用敵 V2 の実ノックバック

## 対象と根拠

`d101a71` の外界強靭・のけぞり時のノックバックと、`7db5055` の既存被弾表示を基準にする。見た目だけだった押し戻しを、既存の試用敵 V2 の攻撃一種類へ接続する。会話ラベルの調整は中止し、本変更には含めない。

## 試用設定

- 打撃元から離れる水平移動を 60Hz の論理フレームで実行。
- 攻撃別定義 `V2Knockback` は 0.05 world/frame × 6 frame、最大 0.3 world の控えめな仮値。正式バランスではない。保存中の設定を変える場合は保存 ID の版と互換定義も合わせて扱う。
- 共通被弾処理で強靭度ブレイクが確定し、生存・のけぞり中の場合だけ開始。確定フレームでは座標を変えず、次フレームから進める。
- ポイズが残る通常ヒット、完全防御、V1 接触・V1 攻撃、ダンジョン戦闘には移動を追加しない。
- 既存の向きを維持し、既存の壁コリジョン、足場、重力、落下処理を通す。崖専用の停止・浮遊・復帰規則は追加しない。新しい無敵時間も追加しない。
- 停止中は論理更新せず、死亡・のけぞり解除・回復・個体交換では残り移動を破棄する。

## 保存

開始済み移動だけを外界 Runtime の省略可能な `Knockback` に保存する。旧保存では null のまま。方向、登録 ID、速度の一致、残り 1～6 フレーム、生存とのけぞり状態を検証してから復元する。攻撃を再実行せず、残りの移動のみを再開する。ダンジョン用コピーには持ち込まない。

## 検証記録

- 新規の関連 24 件は全件成功。左右、非ブレイク、V1、バリア、壁、マップ端、既存の穴・空中落下経路との比較、途中保存と重複復元、登録値改変拒否、個体交換、状態解除、非表示時の更新拒否を含む。
- 初回は新規テストコードの byte[] 型誤りを修正。次の実行では既存 fixture ののけぞり時間 0 と表示中保存禁止を誤って使ったため 8/16 失敗、その次は復帰地点の指定不足で 3/18 失敗。製品の既存契約を緩めず、fixture を明示した最終 24/24 と区別して記録する。
- 全件回帰 6,377/6,377 成功。開始時の Game View は 4K。長時間実行のため内部の実行中フラグと残件数を読み取り、停止・重複実行せず継続。残りの表示テスト中に標準 640×360 へ戻し、完了後に WorldDamageNumberPoolTests を同じ固定サイズで単独再実行して 23/23 成功。製品ソース 424 個は全件の前後で同一。これは描画性能のベンチマークではない。
- 通常 Linux Desktop Player を新規ビルドし、実出力 1280×720、通常形態 Basic、複製セーブでキーボードとマウスを使用。デバッグによる座標・HP書換えなし。
- 左向き押し出し：名札の攻撃 ON 後、HP90/強靭20 と HP80/強靭10 では敵との相対位置が不変。3撃目 HP70/強靭30 で敵から離れる水平移動を映像確認。カメラが主人公を中央に保つため、敵円の画面位置が約22px移り、72px/worldに対する約0.3worldと整合。
- 右壁：通常移動で壁に接してから攻撃を ON。初期HP90（通過時の既存接触被害あり）→80→70→60/強靭30 のブレイクでも壁を越えないことを映像確認。攻撃を OFF にして終了。準備中に接触範囲内で待機して既存 V1 接触死・回復復帰も起きたが、V2押し戻し中の死亡検証とは扱わない。
- 両 Player は通常終了 0、実行時例外なし。元セーブ、設定26件、既存候補16組、製品入力424件のハッシュを最終確認した。
- 通常終了による未確定被害の自動保存を新設していない。約0.1秒の押し出し途中を狙った Player 保存・再起動は未確認。厳密な途中状態の cold 復元は関連回帰で検証。
- 公開は通常の検証済みゲートで実施し、SHAは作業結果側へ記録する。

## 範囲外

正式な押し出しバランス、他の敵・接触・ダンジョンへの拡張、水中専用の外力規則、レベル配置・表示文言の変更は行わない。物理パッド・タッチ、カエン／空中／水中の Native は未検証。左右・穴と空中落下の地形境界は自動回帰の範囲と区別する。
