# 音素材の自作手段調査（2026-10-27）

## 調査範囲と結果

読み取り調査のみ。音声生成・取り込み・外部取得・購入・契約・認証は行っていない。

- Assets以下の `.wav/.ogg/.mp3/.aif/.aiff/.flac` は大文字小文字を無視して0件。
- 現環境に専用の音声/音楽生成ツールは公開されていない。FFmpeg `7.1.5-0+deb13u1` とPython標準 `wave/math/array` は利用可能。SoXは見つからない。
- 外部サービスを使わず、正弦波・ノイズ・短い音量包絡を組み合わせた自作PCM WAVの仮SEを作る手段はある。FFmpegで形式と長さも確認できる。これは手段の確認であり、素材制作済みという意味ではない。

## 登録枠と未接続を区別

- `Assets/Olca/Application/Dungeon/DungeonBattleController.cs` の `dungeonBgm` / `battleBgm` / `uiEffect` は既存のAudioClip登録枠。探索開始/帰還、戦闘開始、既存ボタンの効果音再生へ接続されている。戦闘BGMが未設定なら探索BGMへフォールバックする。
- 調査したScene/Prefabにこの3枠のClip参照はなく、音ファイルもない。既存枠へ自作の仮音を用意する作業と、新しい発音契機を追加するコード作業は分ける。
- `Assets/Olca/Unity/UnityInputProvider.cs` の `GameplayAudioRouter` はBGM/SE/ボイスと停止を扱う。再生APIがあることだけで各攻撃・変身・ガード等の専用SEが接続済みとはしない。今回これらの新しい発音契機/音長/重ね方は追加していない。
- 全体仕様§18の音量区分は全体/BGM/効果音/ボイス。本文はボイス自体を現時点で未実装としており、架空の台詞や話者を補わない。

## 次にできることと境界

既存UI効果音枠の控えめな自作仮SEは、外部取得に依存せず制作可能。BGMは自作も技術上可能だが、この調査では曲調/構成や製品採用値を決めていない。個別キャラ音声・製品別演出音・専用発音規則が必要なものは、素材と契機の不足を分離して扱う。音の都合で既存の戦闘時間や効果判定は変更しない。
