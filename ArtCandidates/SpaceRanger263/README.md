# Space Ranger 263 — 独立キャラクター案

ユーザーの「元デザインと衣装・シルエットを含め明確に異なる、露出を抑えた新デザイン」という依頼による試作。元キャラの衣装差分や、以前に拒否された画像の再現ではない。既存キャラクター・戦闘・セーブへの差し替えは行っていない。UnityのAssets外に候補パックとして保管し、自動でゲームへ組み込まない。

## デザインの相違

元キャラの白髪・顔・細身で暖色中心の輪郭に対し、閉じた紺ヘルメットと不透明なシアンのバイザー、白い厚手ジャケット、太い紺カーゴパンツ、膝当て・大型ブーツ・小型バックパックを採用した。髪と顔は見せず、胴・腕・脚を覆う。紺/白/シアンと少量の黄土色で、宇宙服風の実用的なシルエットにしている。ピクセル調の描画は比較できるが、同一人物・同一体格の互換素材ではない。

5要求すべて成功し、各`*-request.json`に**実際に送ったプロンプト全文・参照パス・透過指定・生成結果とSHA256**を保存した。最初の立ち姿は参照なしの新規生成。以降はこの新案の成功画像だけを参照し、元キャラや拒否画像を参照していない。参照パスは当時の原文を保持しており、パック内ファイルへの対応は各出力SHA256で確認できる。

## 解像度とUnity表示

同梱PNGは生成原本の**1254×1254 RGBA**であり、256角PNGに書き換えたものではない。正規TextureImporterで実256×256・PPU100へ取り込み、Point/Clamp・非圧縮・mipmapなし・alpha0〜255を確認した。全姿勢は新案用の共通pivot `(127,10)`。立ち姿の実不透明最下端も10で、元キャラのpivotを無理に流用していない。空中姿勢の足は接地線へ移動・切抜き・画像変形していない。

再取込用の設定と実Editor読戻しは`unity-import-settings.json`。Unityが新しいGUIDを発行するための設定情報であり、別プロジェクトの`.meta`を配布するものではない。

## 比較と確認範囲

- `game-preview.png`: 既存ゲーム背景・同じ描画倍率で、元キャラと新案5姿勢をUnity GameViewに表示した比較。通常Playerのスクリーンショットではない。
- `motion-preview.mp4`: 実GameViewから回収した固定比較コマによる6秒・640×360・60fps/360frameの表示プレビュー。空中待機36→予備6→接触3→復帰12→空中待機33frameを4回繰り返す。配分は比較用で、ゲームの新しい性能定義や実入力・命中同期の実証ではない。
- 初回3姿勢ではIdleへの急な戻りがあったため、専用予備と空中待機を追加した。最終5姿勢とv2比較動画の独立レビューでは、候補として必須の描き直し指摘0。胴/ヘルメット/腰の大きな位置飛び・衣装混在・靴先の欠けは見当たらない。
- 最終5枚の実256・PPU100・共通pivot・alphaと、原本/候補コピーのSHA一致を検証。既存表示の関連31件成功。製品ソース370件はStage262全4,967件成功時と完全一致し、新たな全件実行はしていない。
