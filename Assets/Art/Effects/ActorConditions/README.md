# ガード・麻痺の独立持続エフェクト（仮素材）

Guard.IsActiveと確定後IsParalyzedだけを読む別レイヤー。ガードは両側からの防御を示す青緑の輪郭、麻痺は中央を避けた黄色の電弧。状態/buffのHUDアイコンやバリア/オーラ輪郭の流用ではない。両方の状態や既存防御フィールドと併存できる。

人物/既存画像参照なしでOpenAI画像生成へ新規依頼。拒否済み攻撃本体の再試行ではない。承認済み最近傍/限定色/透過/中央位置で256角へ書き出す。図案間に生成された区切り線は切出し範囲外とし、alpha0/255・中央96角の完全透過を検証。キャラ画像は変更しない。

Resources/OlcaActorConditions/*.bytesはPNGと同一。ActorConditionVisualは2Spriteを共有し、各状態・各所有者のRendererを再利用する。ガードは本体/防御輪郭より後ろ、麻痺は中央空白の前側レイヤーで、互いの並びを固定。本体の位置/画像/回転/倍率やCoreの判定・時計を変更しない。確定/解除/中断・隠蔽/死亡・再bind・終了/破棄は既存モデル・可視性に従う。独自の点滅時間・寿命を追加しない。.metaを手動編集/公開しない。
