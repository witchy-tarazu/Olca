# バリア・オーラの独立持続エフェクト（仮素材）

既存HasBarrier/HasAuraの確定状態だけへ対応。バリアは青の六角輪郭、オーラは紫の円弧。キャラ本体の描き換え/回転/倍率変更は行わず、別SpriteRendererを背面へ表示する。中央は透過。発生時の攻撃判定や消滅フレーム、効果時間はCoreの既存規則をそのまま使う。

OpenAI画像生成へ人物/既存画像参照なしの輪郭図案を新規依頼。拒否済み攻撃本体の再試行ではない。承認済み最近傍/限定色/透過/中央配置で256×256へ書き出し、alpha0/255と中央96×96の完全透明を検証した。生成原本は検証環境で保持。既存正式/ユーザー素材は置換しない。

Resources/OlcaDefensiveFields/*.bytesはPNGと同一。DefensiveFieldVisualが非圧縮/Pointの2Spriteを共有し、各所有者のRendererは1つだけ再利用。描画は本体boundsに追従し、本体より後ろ・alpha.65。独自の点滅/再生時間を設けない。種類置換/解除/隠蔽/死亡/無効化/破棄では消去する。.metaは手動編集/公開しない。

持続フィールド素材であり、ガードの被弾演出、変身や麻痺の専用コマ、音素材まで完成したものではない。

actor-bounds.jsonは既存敵画像の不透明領域から生成した描画校正。元画像/SHAとpixel bboxを記録し、既知名/寸法だけへ適用。透明な余白ごと輪を描く位置ずれを防ぐ。性能値やキャラ本体は変更しない。
