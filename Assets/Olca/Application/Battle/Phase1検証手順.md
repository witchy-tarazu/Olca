# フェーズ1 バトルシステム検証手順

## 概要
フェーズ1で実装したコアシステム（バトルシステム、カードシステム、カスタム画面）の動作確認を行います。

## 検証環境
- Unity バージョン: 6000.0.60f1
- シーン: `Assets/Scenes/Phase1BattlePrototype.unity`
- コントローラー: `BattlePrototypeController.cs`

---

## セットアップ手順

### 1. シーンを作成
1. Unity エディタで `File > New Scene` を選択
2. `Basic (Built-in)` または `Basic (URP)` を選択（プロジェクト設定に合わせる）
3. `File > Save As...` で `Assets/Scenes/Phase1BattlePrototype` として保存

### 2. BattlePrototypeコントローラーをセットアップ
1. Hierarchy で右クリック > `Create Empty` を選択
2. 作成されたGameObjectの名前を `BattlePrototype` に変更
3. Inspector で `Add Component` をクリック
4. 検索欄に `BattlePrototypeController` と入力して選択
5. コンポーネントがアタッチされたことを確認

### 3. 再生
1. Unity エディタで再生ボタン（▶）を押す
2. `Window > General > Console` を開いて、ログを確認できるようにする
3. Game ビューを確認して、画面左上にステータスが表示されることを確認

---

## 検証項目

### ✅ 初期化確認
**期待される動作:**
- Consoleに以下のログが表示される
  ```
  [INFO] === バトルプロトタイプ開始 ===
  [INFO] プレイヤーHP: 100/100
  [INFO] 敵の数: 2
  [INFO] 操作方法:
  [INFO] - Z: スライムに攻撃
  [INFO] - X: ファイアーに攻撃
  [INFO] - C: カスタム画面（ゲージ満タン時）
  [INFO] - Space: プレイヤーにダメージ（テスト用）
  ```

- Game ビュー左上に以下が表示される
  ```
  バトルプロトタイプ（フェーズ1）
  プレイヤーHP: 100/100
  カスタムゲージ: 0%
  敵一覧:
    1. スライム - HP:30/30 (None)
    2. ファイアー - HP:50/50 (Fire)
  ```

---

### ✅ 基本攻撃（プレイヤー → 敵）

#### テスト1: スライムへの攻撃
**操作:** Zキーを押す

**期待される動作:**
- Consoleに `[INFO] プレイヤーの攻撃！ スライムに15ダメージ` が表示される
- Game ビューのスライムHPが `30 → 15` に減少

**繰り返しテスト:**
- もう一度Zキーを押す
- スライムのHPが `15 → 0` になる
- `[INFO] スライムを撃破！` が表示される
- Game ビューで `スライム - 撃破済み` と表示される

#### テスト2: ファイアーへの攻撃
**操作:** Xキーを押す

**期待される動作:**
- Consoleに `[INFO] プレイヤーの攻撃！ ファイアーに15ダメージ` が表示される
- Game ビューのファイアーHPが `50 → 35` に減少

---

### ✅ プレイヤーダメージ（テスト用）

**操作:** Spaceキーを押す

**期待される動作:**
- Consoleに以下が表示される
  ```
  [WARNING] プレイヤーが10ダメージを受けた（テスト）
  [INFO] プレイヤーHP: 90/100 (90%)
  ```
- Game ビューのプレイヤーHPが `100 → 90` に減少

**繰り返しテスト:**
- Spaceキーを10回押す
- プレイヤーHPが0になる
- `[ERROR] ========== 敗北... ==========` が表示される
- Game ビューに赤文字で「敗北...」と表示される

---

### ✅ カスタムゲージシステム

#### テスト3: ゲージの自動増加
**操作:** 何も押さずに待機

**期待される動作:**
- Game ビューのカスタムゲージが徐々に増加する
  - `0% → 10% → 20% → ... → 100%`
- ゲージが100%に達すると、Consoleに以下が表示される
  ```
  [INFO] *** カスタムゲージ満タン！Cキーでカスタム画面を開けます ***
  ```

#### テスト4: カスタム画面を開く
**操作:** ゲージが満タンになったらCキーを押す

**期待される動作:**
- Consoleに以下のような内容が表示される
  ```
  [INFO] === カスタム画面を開く ===
  [INFO] ドロー可能なカード（5枚）:
  [INFO]   - キャノン (コスト:2, 攻撃力:40)
  [INFO]   - ソード (コスト:1, 攻撃力:20)
  [INFO]   - リカバリー (コスト:3, 防御, 攻撃力:30)
  [INFO]   - ウォーターボール (コスト:2, 攻撃力:30)
  [INFO]   - フレイムソード (コスト:3, 攻撃力:50)
  [INFO] 最大コスト: 5
  [INFO] ※実際のゲームではUIで選択しますが、今回は自動で全選択します
  [INFO] 選択: キャノン
  [INFO] 選択: ソード
  [INFO] 選択: リカバリー
  [INFO] 合計3枚選択
  [INFO] === カスタム画面を閉じる ===
  ```
  ※カードのドロー順はランダムなので、順番は異なる可能性があります

- ゲージが0%にリセットされる

---

### ✅ 勝利条件

**操作:** 敵を全滅させる
1. Zキーを2回押して、スライムを撃破
2. Xキーを4回押して、ファイアーを撃破

**期待される動作:**
- Consoleに以下が表示される
  ```
  [INFO] スライムを撃破！
  [INFO] ファイアーを撃破！
  [INFO] ========== 勝利！ ==========
  ```
- Game ビューに緑文字で「勝利！」と表示される
- 両方の敵が「撃破済み」と表示される

---

### ✅ 敗北条件

**操作:** プレイヤーのHPを0にする
1. Spaceキーを10回押す

**期待される動作:**
- Consoleに以下が表示される
  ```
  [INFO] プレイヤーHP: 0/100 (0%)
  [ERROR] ========== 敗北... ==========
  ```
- Game ビューに赤文字で「敗北...」と表示される

## 検証後のチェック項目

### コアロジックの動作確認
- [x] PlayerCharacter: HP管理、ダメージ処理、イベント発火
- [x] Enemy: HP管理、属性、撃破判定
- [x] Deck: カードの管理
- [x] CustomGaugeSystem: ゲージの自動増加、満タン判定
- [x] BattleSystem: 勝敗判定、ポーズ/再開
- [x] CustomScreenSystem: カード選択、コスト管理

### Unity非依存性の確認
- [x] Core層のロジックがMonoBehaviourに依存していない
- [x] IRandomProvider経由でランダム処理を行っている
- [x] ITimeProvider経由でdeltaTimeを受け取っている
- [x] IInputProvider経由で入力を受け取っている
- [x] IGameLogger経由でログ出力を行っている

### イベント駆動の確認
- [x] OnHpChanged: プレイヤーのHP変化時に発火
- [x] OnDeath: プレイヤー/敵の死亡時に発火
- [x] OnGaugeFull: ゲージ満タン時に発火
- [x] OnBattleEnd: バトル終了時に発火

## トラブルシューティング

### BattlePrototypeControllerがアタッチされていない
1. Hierarchy で `BattlePrototype` GameObjectを選択
2. Inspector で `Add Component` をクリック
3. `BattlePrototypeController` を検索して追加

### ログが表示されない
1. Unity エディタで `Window > General > Console` を開く
2. Console ウィンドウの右上の設定で、`Info`, `Warning`, `Error` すべてにチェックが入っていることを確認

### 入力が効かない
1. Game ビューがフォーカスされていることを確認（クリックしてアクティブに）
2. 再生モードになっていることを確認（再生ボタンが青色）
