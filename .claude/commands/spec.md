Olcaプロジェクトの**仕様書を参照**して、実装に必要なルール・ロジックをサマリーします。

## 参照したい仕様
$ARGUMENTS

## 仕様書の構成（必ず理解してから参照すること）

```
Planning/
├── バトルシステムについて   # ゲームロジック仕様（コスト計算、選択ルール等）
├── ダンジョンについて       # ダンジョンシステム仕様
└── ビジュアル・アート/      # UI/UXのみ（ゲームロジックは含まない）
    ├── UIデザイン仕様.md
    └── カスタム画面仕様.md
```

**重要な役割分担:**
- **ゲームロジック実装** → `Planning/バトルシステムについて`、`Planning/ダンジョンについて` を参照
- **UI・画面表現の実装** → `Planning/ビジュアル・アート/` を参照
- 両方が必要な機能（例: カスタム画面）は**両方を参照して使い分ける**

## 調査手順

1. 引数のキーワードに関連する仕様書ファイルを特定する
2. 該当ファイルを読み込み、関連する章・節を抽出する
3. ゲームロジック仕様とUI仕様を**明確に区別**してサマリーする

## 出力形式

日本語で以下の形式で報告：

```
## 仕様サマリー: [機能名]

### ゲームロジック仕様（Core層実装の根拠）
- （計算式、判定ルール、状態遷移など）

### UI・表示仕様（Presentation層実装の根拠）
- （レイアウト、アニメーション、色・サイズなど）

### 実装上の注意点
- （仕様書から読み取れる制約・特殊ケース）

### 参照元
- ファイル名: 該当箇所
```

---

Task toolを使い、`subagent_type: "Explore"` で仕様書を調査してください。
