# Olca Spec

`Planning/` 配下の仕様書から、実装に必要なルールと制約を抽出する。

## 参照先

```text
Planning/
├── バトルシステムについて   # ゲームロジック仕様
├── ダンジョンについて       # ダンジョン仕様
└── ビジュアル・アート/      # UI/UX、画面表現
```

## 調査手順

1. ユーザーの依頼に関係する仕様書ファイルを特定する。
2. 該当章を読み、ゲームロジック仕様とUI・表示仕様を分ける。
3. Core層で実装すべき判定、計算式、状態遷移を抽出する。
4. Presentation層で扱うレイアウト、演出、色、サイズ、操作感を抽出する。
5. 仕様書にない推測は「推測」または「未記載」として明示する。

## 出力形式

```text
## 仕様サマリー: [機能名]

### ゲームロジック仕様（Core層実装の根拠）
- ...

### UI・表示仕様（Presentation層実装の根拠）
- ...

### 実装上の注意点
- ...

### 参照元
- ファイル名: 該当箇所
```
