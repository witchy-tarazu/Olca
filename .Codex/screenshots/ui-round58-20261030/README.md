# 出撃先・出撃操作の視覚整理（Round58）

スタイルの次に、既存の出撃先画面を水鏡の見出し・本文・操作面へ整理。元背景・JikiTourai・文字表記規則・行1450×78と主操作位置を保持し、性能・解放・進行・費用・保存形式・時間を変更しない。

- 密な一覧は選択先の敵属性／地形を上部に維持。少数候補時は大きな空白を選択先情報の面へ使い、名前と情報を分けて表示する。元データはControllerの既存DungeonDeparturePreviewからの情報であり、新しい性能や推奨値は作らない。
- 原寸レビューで上部案内の枠線交差と右上マス解放の面重なりを修正。一覧行を32基準px下げて補助操作との間隔を確保し、行サイズと選択・主操作の意味は保持。選択レールと明暗の階層を追加し、一覧・ページ・主操作・補助操作を整理。空一覧と出撃不可には案内を表示し、確定を無効にする。未解放の名前／詳細は非公開のまま、既存の条件とクリア履歴を保持。
- ControllerのinitialHubを表示へ渡し、初期拠点では「この行き先で出撃」、帰還後は「行き先を確定」とする。後者が出撃を開始するような案内を避ける。新しい確認ダイアログやゲーム動作は追加していない。optional引数とページ変更で既存呼出互換を維持する。
- 今回は既存の選択先情報・保存済みスタイルの表示接続と構成変更。公開された出撃先モデルに専用画像参照はなく、無関係なカード絵や地形画像を流用しない。新規ラスタや製品値の追加はない。拒否済み画像生成を再試行していない。

根拠はゲーム全体仕様のダンジョン選択／解放条件／クリア履歴、既存RenderDungeonSelection、ShowDungeonSelectionの初期拠点と帰還後分岐、FormatDungeonInformation。推奨レベルなど未供給の製品値を絵の都合で決めない。

## 実操作と検証

隔離保存先と実EventSystem Raycast経路で、選択・ページ往復・取消を2周、スタイル子画面からの戻りfocus、選択だけでは保存や出撃が起きないことを確認。初期拠点から実出撃→休止→撤退→帰還の経路を通し、帰還後の行き先確定では保存や2回目の出撃を起こさず、再表示へ選択を保持することを確認。同じ保存先のPlay再起動でも保存profileが一致する。検証のラベル参照名を実名へ修正して帰還済み状態から継続し、Play再読込の接続切れ／待機Task timeoutでは既存実行の完了とprofile一致を読み取り確認して再初期化を重複しなかった。通常の最終Playはconsole error0。

初回のprivate階層定義は6枚用だった一方、保存デッキは20枚でfire_swordを含み、出撃時の一時メモリ捕捉が未登録定義で停止した。Root802は保持し、未登録定義を許す変更は行わない。6枚定義へ20枚を渡すと失敗、20枚を正規登録した定義では成功するメモリ再現を記録。private初期化を公開TryConfigureDepartureDeckで同じ20枚に揃えたRoot803で実操作を再確認した。製品Core／保存規則は不変。

関連615件成功。最終全EditModeは実640×360・専用TMPDIR／保存ガードで1回起動して結果を回収する。再コンパイル直後の接続失敗は、同じEditorの通常ドメイン再読込と7800番port復帰を実ログで確認してから、まだ起動されていなかった関連テストを開始した。Editor／VM再起動・認証変更はない。

初回全件は3493成功／1失敗だった。少数候補時の敵属性／地形を意図的にプレビューへ移したため、旧説明欄だけを参照した既存テストを、activeなプレビューとスタイル説明へ追従させた。同じ値・未解放拒否・revision不変・出撃未開始の期待を維持し、独立レビューで緩和でないことを確認した（prior-full-tests.json）。

調整中の説明欄70px化で既存長文テスト3件が失敗したため、80pxへ戻して位置で解決し、同じ期待値で再成功した。停止せず行った初期のPlay中再コンパイルでは、未変更WorldBattleGridView.RefreshTelegraphs／OnEnableの配列例外を検出した（historical-domainreload-error.json）。後続は通常停止してからコンパイルした。例外を修正済みとはせず、通常の最終Play／保存再読込consoleと区別して記録する。

独立コードレビューと原寸視覚レビューの範囲・指摘対応はreviews.json、実操作はoperations.json、原本保護・低解像度／入力復元はcleanup.json／input-cleanup.json。全件警告は実ログで分類しerror0と混同しない。警告抑制や期待値緩和は行っていない。

物理パッド／タッチ／IMEと実機ビルドは未確認。この単位の視覚・保存導線検証であり、ゲーム全体の美的完成や無欠陥保証ではない。未定義の製品値や拒否済み本体モーション素材を完成扱いにしていない。

最終全 **3,494件成功**（272.28秒、失敗／skip0）。console error0／warning62を分類。
