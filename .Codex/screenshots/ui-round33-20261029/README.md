初回の敗北・撤退の境界停止画像は文字が断片化して判読不能だったため、表示正常の根拠として不採用にした。保存済み帰還を同じEditorの新しいPlayで再表示し、Editorを停止せず解像度ごとに2回描画して再取得したところ、FHD／4Kとも判読可能になった。進行／checkpoint／設定ファイルhashと終了記録1件は不変。Editor停止直後の描画更新待ちと整合する現象であり、フォントや製品コードを追加変更して直したものではない。旧画像は私用証跡に保持し、上記4枚を安定画像へ差し替えた。

専用saveは `save/ui-round33-outcome-battle-v190`（勝利）、`v191`（敗北）、`v192`（撤退）。修正前はv189を使用。実ユーザーsaveは操作せず、実保存への障害注入や破壊的変更も行わない。
