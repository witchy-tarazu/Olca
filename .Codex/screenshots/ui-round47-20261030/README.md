# Round 47: 複数状態アイコンと戦闘HUDの余白

基準master `7f2252cef66aec2c4582e1293e2919c216ce15b1`。開始時・画像検証後の通常fetch/pullで追加仕様更新なし。`Planning/ゲーム全体仕様.md` §7の「自分はHP近傍、ボスは右ゲージ近傍、通常敵は表示しない、残時間の数値を増やさず灰色割合で示す」に沿う表示調整。

## 変更

- プレイヤーの状態列をHP文字の子から独立した描画ドックへ。カスタム開閉・4:3縮小でアイコンまで小さくならず、4列で整列する。閉状態はHPの下かつゲージ外側、開状態はカスタム外周の右へ追従。画面を隠す間は明示的に消し、復帰時は同じスロットを再利用する。
- 48論理UI単位のタイル、内側40単位の図柄、6単位の間隔に統一。FHD／1440×1080でタイル48px、4Kで96px。4:3開状態の従来約28pxの縮小を解消。小さい余白を付け、残量のグレー部分も暗い背景から分ける。
- 新しい画像を増やさず、既存の `Resources/OlcaUI/description` を細いスライス枠として状態表示にも接続。プレイヤー／ボスで共有し、入力は受けない。元の状態絵や共有Spriteを編集・破棄しない。
- ボスは有効なHP／強靭度ゲージの実左外周を基準に配置。アイコン寸法の1/4（1080高で約12.15px）を空け、広すぎたゲージとの空きを詰めて防御フィールド縁との競合を減らす。複数ボスの既存レーンは維持する。

背景・JikiTourai・キャラの位置/倍率・カード配置・入力範囲・残時間・効果・固定論理時計・コスト・報酬・保存形式・Unityのserialized参照は変更しない。
