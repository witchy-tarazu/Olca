# トークン交換画面の視覚整理（Round56）

出撃先・スタイル・交換の実画面を確認し、価格・所持数・回数制限が一行に混在し、商品数が少ないと明るい空白が支配していた交換画面を最初のまとまりに選んだ。出撃先／スタイル本体の全面的な視覚調整は次の対象とし、今回完成した扱いにしない。

- 残高と見出し、商品一覧、確定内容を水鏡の面材で分ける。元背景・JikiTourai・既存ボタンを維持し、商品行1730×76と行／ページ／確定操作の座標は変えない。
- 商品名＋専用mini、価格、所持／回数制限を列揃え。初案の右列3行が枠に近かったため、独立価格列と状態2行へ変更し、上下12基準pxの余白を確保した。商品数が少ないページは背景だけを最終行下端＋32pxまで短縮する。
- 型上限の価格が24文字中11文字しか描かれない境界を確認し、価格欄だけ20〜30の局所bestFitで全桁を保持する。最大桁側は数値と単位を明示的に2行に分け、価格の右端を保って欄を局所的に広げる。数値の途中で行を分けない。製品価格は変えない。
- 名前だけを36文字要素で省略し、超越段階★は省略の外側へ保持。選択後の確定内容には原文を残し、長文は既存の読み取り専用全文へ接続する。空一覧では選択を促さず、戻る操作を案内する。
- 商品IDで行を保持し、保存済みカードID／名称／段階／rarity／定義hashを既存resolverへ渡し、既存のソード・ヒール・シールドminiを接続。解決不能な同名別定義へ画像を借用しない。Imageは等比・非入力で、借用Spriteの所有権を変更しない。
- Controller／Core／価格・消費・回数制限・更新・上限変換・受領履歴／保存形式は無変更。新しい絵・価格・スタイル値は登録しない。専用miniの接続であり、カード本絵や攻撃本体モーションの作成とは別である。

根拠はゲーム全体仕様§12（カードごと4枚・超過変換・固定／ランダム商品・再抽選禁止・回数制限）、既存ExchangeOfferData／ClearReturnSession／Controllerの交換経路。これらのルールを変更しない。
