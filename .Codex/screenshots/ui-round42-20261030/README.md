## 見た目の変更

旧画面は10ボタンが画面下方に散在し、攻略操作と設定の区別や見出しがなく、中央〜右下へ視線が分散していた。同じ通常探索／デッキ6・獲得0／ポーズのFHD実画面から着手した。

- 既存の水鏡window素材を中央1440×840の透過パネルへ再利用。元背景やキャラの座標・等倍、既存JikiTourai、青白いUI方向を変更しない。
- 左に攻略操作4個、右に設定6個を整理。大見出し・区分見出し・細い仕切りで階層を作り、再開を左上の初期フォーカスとして維持。
- ボタン高88、文字の左右18／上下6の内側余白と最大28のJikiTouraiへ統一。長い設定の項目と現在値は明示的に2行とする。
- ポーズの暗幕だけを濃い青へ調整し、背面HUDの露出が主画面より目立たないようにする。背面オブジェクトの有効・無効や寿命は変えない。

製品差分はDungeonBattleController.csのみ。既存ボタンのID・親・購読・保存操作・取消・再開・固定論理時間は維持。装飾は非raycastで、既存の全面overlayが背面入力を遮断する。ラスタ素材の新規生成や切貼りは不要で、既存の正式な共通素材を利用した。meta、Scene参照、保存形式・製品性能を変更していない。

## 目視と反復

最初の案を実画面で見て長文の内側余白を調整。独立の見た目レビューで出た「設定項目／値を分離」「背面の減光」を反映し、さらに2行文字の上下余白のため76→88へ高くした。自動テストだけで外観の良否を決めていない。

最終FHD／4K／4:3を主担当と独立担当が目視。10ボタンはpanel内・相互非重複、フォントJikiTourai。音量・キー・パッド設定、所持カード、撤退確認を各2回、実際のUI pointer経路で開閉・取消し、毎回pauseへ復帰。前後の専用保存JSONハッシュは不変。振動やIMEの物理機器を使った検証ではない。

振動／演出の保存エラー文はTextだけの隔離fixtureで19／24文字を表示。76高の文字領域に必要高59以下で2行、画像でも読める。実セーブへ障害を注入しておらず、保存失敗や再試行の実再現とは報告しない。表示fixtureはPlay終了で破棄。
