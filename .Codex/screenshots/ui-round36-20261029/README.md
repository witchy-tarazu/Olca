### 購入・削除・回復を行う経路

検証用マップで初戦→既存通貨報酬10→ショップ→回復イベント→隣接する次敵の順に通常進行した。ショップは検証用のカード購入5／1枚削除5、回復は検証用+7。これらは分岐を通すfixture値で、製品の登録値や仕様を変更・決定するものではない。初戦の撃破だけfixtureで成立させ、その後は既存UIをポインタ操作した。

- 購入選択・取消では通貨10／デッキ6／取得0のまま。購入確定ボタンへdown/up/clickを3回続けても通貨5／デッキ7／取得1に一度だけ変化した。
- 削除対象を選んで戻っても支払・削除なし。選び直して確定を3回送っても通貨0／デッキ6／取得履歴1で、永続所持や持帰り履歴を追加で減らさない。
- 上記の未退出時にはチェックポイントSequenceは変わらず、退出操作後のFileCheckpointStoreは通貨0／デッキ6／取得1／ショップ閉鎖と一致。確定済み購入は、その後の別取引取消では取り消していない。
- 回復用にHP80をfixture設定。回復選択取消で80のまま、確定3回でも87に一度だけ回復した。
- 仮想padのDpadRightを押し続けてイベント退出→隣接敵へ接触。接敵回数は計2、カスタムは選択0／カーソル0／戦闘0論理frame、HP87。探索ボタンや訪問モーダルは戦闘へ残らず、Controllerの対象イベント購読は各1。
- 最終チェックポイントは両訪問Closed、購入済みフラグ、通貨0／デッキ6／取得1と実状態が一致した。
