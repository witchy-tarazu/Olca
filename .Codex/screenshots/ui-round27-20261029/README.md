# 戦闘・探索の撤退確認と復帰（2026-10-29）

通常Controllerから専用の短いダンジョンを起動し、戦闘カスタム→ポーズ→撤退確認を実操作した。撤退確認中にも右上の図鑑ボタンが残り、押すと確認画面の上へ図鑑を開けた。また、撤退／戻るの2ボタンは200px幅から文言がはみ出した。

図鑑の既存表示条件をCardCollectionUiAvailableへまとめ、撤退確認中を除外し、ボタン操作受付にも同じ条件を適用した。融合履歴の保存失敗から自動で開く内部復旧経路は維持した。通常ポーズからは図鑑を引き続き開ける。撤退／戻るボタンは既存の中心位置・高さを保ち、幅を420pxにした。背景・JikiTourai・文言の意味・性能時間・保存形式・Unity参照は変更しない。

## 確認範囲と限界

- 探索／戦闘の新2回帰で、確認中の古い図鑑onClickを拒否し、取消後の図鑑開閉、ポーズとカスタム・論理frame保持を確認。保存はMemoryStoreの隔離入力。
- 実Playの戦闘2周で、撤退確認中の入口非表示・古い操作拒否、取消→図鑑→ポーズ→カスタム復帰、状態詳細を開いたままポーズ／復帰を確認。カスタム中は論理frame0・描画時計停止を保持。最初の通常図鑑登録後から専用save不変。
- 探索でも確認の取消と明示再開を確認。最初の短いマップでは画像取得中にカウントが完了し接敵して、監査スクリプトの探索中という前提が外れた。製品テスト失敗とせず記録をprivate保持。敵まで遠い別の隔離マップで再開を確認し、途中再停止はControllerの既存15論理frame直接呼出しで制御して検証した。実OS通知・実機入力の検証とは区別する。
- 実保存障害注入は行っていない。高解像度画像は実時間／FPSの保証ではない。音声聴感・物理pad・実OS focus通知・ダメージと状態表示の戦闘中更新境界は今回の完了に含めない。
