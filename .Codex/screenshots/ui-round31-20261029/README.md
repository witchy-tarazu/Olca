# ボスの浮遊ダメージ数値・上端境界（round31）

通常のController戦闘経路に隔離定義（ボス100HP＋通常敵50/80HP）を供給し、3体へ7ダメージを与えた。製品定義・ダメージ値・効果時間・固定論理frame・素材・背景・JikiTourai・保存形式は変更していない。

## 同条件の比較

- FHD：[修正前](before-fhd.png) → [最終修正後・カスタム表示中](after-visible-fhd.png)
- 4K：[修正前](before-4k.png) → [最終修正後・カスタム表示中](after-visible-4k.png)

修正前はボス「7」のRenderer上端がviewport **1.0084126**となり画面外へ切れる。最終ソースでは上端を8px内側へ保つ（FHD上端 **0.992592454**、4Kは約**0.996296**）。上下だけの個別clampでは同対象の数値が重なるため、既存Poolのowner群全体へ共通補正を適用する。下げた群が対象のTextMeshラベルに重なる場合だけ、画面内・ラベル非重複を満たす横側へ寄せる。通常敵2体は元の位置を維持する。

修正前のカスタム非表示切替は撮影時に完了していなかったため、比較相手も明示的にカスタム表示中へ揃えた。背景やUIの切替途中の差を修正効果とは扱わない。

## 範囲と限界

左右のどちらにも収まる余地がない任意の巨大な表示群に対して、常にラベルとの非重複を保証する処理ではない。今回のボス＋通常2体、単発7・同時3/5および回帰条件の結果として扱う。次の有益な実画面観点は、回復・ガード・無効など文字幅の異なる既存フィードバックの画面端／HUDとの競合。未決値を追加するための候補ではない。
