# 独立原寸視覚レビュー

independent_refactor_reviewがbefore common3枚とafter common/dense/empty各3枚を個別に確認。静止画の今回範囲で残る必須指摘0。ゲーム全体の無欠陥／ユーザーの美的承認を意味しない。

- before: 名称・Normal・威力・編成/所持が同じ一続き、名称長により数量位置が動く。±の近くの採用数と独立所持列を推奨。4:3は上部説明と一覧の主従が弱い。
- final common: 名称/Normal→副段の威力、±間の編成数と右所持数へ分離し、2/4と0/4を追える。明るい水鏡面と濃色文字は可読。2面に留まり枠過剰なし。4:3のルールは小さめだが副情報として許容、主要情報は読める。
- dense: 同名でもmini/威力30・41/編成1・3を別行で追える。長名の全文入口と性能詳細が分離し、数量列へ侵入しない。6行目の威力と下枠は離れている。
- empty: 所持なし・スターター非自動付与が明瞭。0/20と必要20枚の案内は整合。空面は広いが通常一覧との操作位置維持の範囲で許容、装飾で埋めない。
- raw名入力「検証」は既存の生文字保持契約でありラベル変換漏れに数えない。

レビューは編集/MCP操作なし。実入力・保存・テストの実績は主担当の記録と分離。
