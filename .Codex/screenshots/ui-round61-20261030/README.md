# 攻撃対象予告とマグマ床の視覚分離（Round61）

赤い面と枠だけだった予告と赤く染まったマグマを、色以外でも見分ける表示へ整理する。Round60の初手5枚・同じ論理時計のカメラ追従・出撃先の簡素化・前景の継ぎ目修正は保持する。

## 変更と見直し

- 予告は薄い面、クリーム色の角括弧と「!」へ。床の原絵とキャラクターの足を見通せるよう、全面の赤い枠／塗りを減らした。対象マスの集合・予告開始／終了・重複時1表示の規則は変えない。
- マグマは元の床Spriteを保持し、暗赤の割れ目と短い橙の明部を重ねる。不均一な亀裂を共有可能な描画部品として実装し、戦闘と探索から参照する。新しいラスタ画像、元背景／Spriteの加工、キャラクター生成はしていない。
- 初案は独立原寸レビューで「ネオン線」、次案は「穴のように暗い床」と指摘された。線幅と明部の長さ、岩の明暗を見直し、最終の戦闘6画像で具体的な未解決指摘0を確認した。探索の明るい薄板も完成扱いにせず、暗橙半透過の接地帯と床面内の亀裂へ修正した。
- 模様は既存rootの表示寿命へ従い、生成済み部品を再利用する。借用Spriteの所有権を移さず、地形変更・Disable／Enable・再読込で現在の状態を表示する。Core、時間、ダメージ、判定、保存形式、元床と本体の位置／Sprite scaleは変更しない。探索の表示帯のみ上端を接地面へ合わせる。

## 実プレイと検証用定義の区別

通常Sceneの新規開始→実EventSystem Raycast出撃→実際の接敵→初回カスタム5枚→確定を通してから、同じ実BattleSystem上で既存APIへ検証用の予告カードとマグマを入力した。現在の製品既定敵は即時BasicAttackで、既定探索地形は氷のみである。30発生／15硬直の予告カードと地形位置は**検証専用・製品未登録**であり、新しい製品AIや性能値を作成したものではない。これは実画面上の既存表示機構の確認であり、製品の予備モーション連番完成とは別。

比較画像は同じ解像度・同じ本体位置／HP100／地形0・3、マグマのみは論理frame1、予告併存はframe6・対象1／2／3で取得。探索は既存マップの他条件を保つ隔離定義へマグマ2セルを与えた**変更後のみの確認画像**。製品マップや実保存は書き換えない。

停止中の論理frameと予告集合は不変。再開後の実EnemyCardAction自然発動で10damage、強靭度を削る既存Core被弾入力で予告取消、実ポーズ→チェックポイント読込で一時地形／予告を消去し、保存hash不変を確認した。取消確認は物理攻撃入力ではなく既存Coreへの検証入力として区別する。探索は実自動進行で2セルの既存5damageを受け、見た目／地形種別が残ることを確認する。
