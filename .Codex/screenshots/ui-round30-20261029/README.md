## 上限と操作

16文字（NFCで数えるテキスト要素、保存原文は変更なし）かつ一覧行幅680px以内。JikiTourai25pxの実計測で、装備中・20枚込みの16全角文字は663px、18文字は713px。領域700pxへ余白を確保する。詳しくは `Planning/デッキ名入力上限-20261029.md`。

隔離セーブで新名保存、複製、旧名完全一致保存、部分削除→取消のファイル不変、確定B→編集C→EscapeでBへ復帰、破棄済み画面の旧確定コールバック無効、保存一覧再読込を確認した。実製品・ユーザーセーブは使用していない。APIからの日本語/結合文字/サロゲート回帰とUnityクリップボードイベントを確認したが、物理IMEでの変換・確定は未検証。
