# 同位置の敵名と複数敵・ボスHUD（2026-10-29）

通常Controllerでボスへ直接接敵し、通常敵2体を巻き込む既存経路を検証した。同じ位置にいるザコA/BはHP円50/80が分離されているのに名前が重なり、一方を読めない問題を再現。画像は加工なしのGameView原本。寸法・SHA256はmanifest参照。

同位置の通常敵だけ名前を自分のHP円の左へ対応させ、名前の右端と円の間に余白を取った。円の位置・行間、本体、フォント、文字の大きさとscaleは維持。毎更新で原点から求め直し、再初期化も復元してずれを蓄積しない。単独時は元の名前位置、ボス固定HUDは従来どおり。

- 個体別の7被弾・7強靭度ダメージ：[FHD](hurt-fhd.png)／[4K](hurt-4k.png)。HP93/43/73、強靭度23/30。投入はBattleSystem.RunLogicalFrameによる制御検証で、製品攻撃値は変更していない。
- 敵詳細の順切替：[ボス](boss-details-fhd.png)／[ザコA](normal-details-fhd.png)。ボス→A→B→ボスの周回と、撃破後のA→Bを確認。
- ボス撃破後の生存HUD：[FHD](after-death-fhd.png)／[4K](after-death-4k.png)。カスタム停止中はボスのゲージ／アイコンを即座に隠し、死亡本体は描画再開後に消去する。生存2体のHP43/73は維持。

ボス100・通常50/80、強靭度30、7ダメージ、撃破999等は隔離データで製品登録なし。仕様§7に従い、通常経路に複数ボスを巻き込む変更はしていない。最初にボスを主敵にしないfixtureで通常敵1体だけ参加することを確認し、主敵ボス＋通常巻込へ検証設定を訂正した。

2体／6体の名前bounds非重複・HPとのY対応・反復・再初期化と単独復帰の新2回帰、関連10件、最終全件と独立レビューはPlanning参照。通常PlayとFHD／4Kの実Jiki字体も確認し、専用saveは検証前後hash不変。

背景・JikiTourai・固定frame・性能時間・保存／Unity参照は維持。実機pad／OS通知・聴感・実保存障害・任意の極端な長名の画面端・高解像度の時間保証は未確認。別の改善候補として、被弾画像でボスのダメージ数字が上端にかかる点を確認した。今回の名前分離修正と、HP／状態の同期合格には混ぜず次の再現調査対象とする。
