# Round50: 報酬カードの本絵・情報階層とショップ袋素材

報酬カードの空白が大きく、本絵がなく、小さいLegacyフォントのラベルが散在していた表示を改善した。既存の専用カード本絵を借用して正方形・比率維持で表示し、JikiTouraiによる名前→本絵→コスト／レギュレーション→説明→獲得の順へ整理した。miniアイコンの拡大ではない。既存の水／鏡の青白い共通パネルを使用し、背景やキャラには変更を加えていない。

上部の見出し・現在枚数・戦闘時間を一つのパネルへまとめ、4:3では常設HUDを避けて幅を絞った。独立レビューで発見した低い横長画面のヘッダーとの重なりも、上下の利用領域から縮尺と中心位置を計算して修正した。FHD／4Kの位置は維持。カード定義の原文は保持し、表示だけ漢字部分を既存変換でカタカナ化する。説明をスクロール領域とし、長文時だけ細いバーを表示する。通常文では非表示で、フォーカス項目を増やさない。

## 作成した不足素材

`Assets/Art/UI/Visits/shop_bag.png`と同一bytesの`Assets/Resources/OlcaVisits/shop_bag.bytes`を新規登録した。従来6矩形だった袋の内側だけを、独立した買い物袋glyphへ置換する。外枠・矢印・チェック・状態色・透明度・カリング・位置・既存判定はそのまま。

OpenAI画像生成ツールでキャラを含まない袋を1回生成し、許可済みのゲーム用書出しで64×64、3階調、alpha 0/255へ整えた。拒否済みキャラ画像の再使用・再試行はしていない。16／20／24pxの識別を確認。[実シーンのワールドカメラ画像](shop-camera-fhd.png)でも袋を確認した。この画像はOverlayを含む通常GameViewではない。公式のcamera取得経路で描画し、撮影中はEditorを停止したまま、位置0.4・未入店・通貨0・6枚と保存2ファイル、カメラのtargetを撮影前後で保持した（[記録](shop-camera-invariance.json)）。画像のためにモーダルを隠したり探索を進めたりしていない。新規の武器性能や敵・商品データは追加していない。Viewが生成したSprite／Textureだけを所有し、再表示で再利用、破棄時に解放する。借用Resourcesは破棄しない。

## 操作とレビュー

報酬は実Raycastで選択し、古い選択入力を再送しても、通貨確認後の保存はデッキ6→7／獲得1／通貨10だった。通貨確認前の一時状態を保存完了と誤認しない。別runの報酬・通貨スキップでは6枚／獲得0／通貨0で探索へ戻った。店では選択取消・ポーズ往復・退出を確認し、未購入での保存を保持した。全て専用の検証保存先で実施し、製品保存に障害を注入していない。

独立したコード・原寸視覚レビューを反復した。横長の重なりと長文の続きの手掛かりの2指摘を修正し、最終の各レビュー範囲で具体的な未解決指摘0。これはゲーム全体や美観の完成を保証しない。

## 今回の区切りと次の具体候補

今回の画面改修は報酬カード群、素材補完はショップの袋1点。帰還やショップの本体パネル全体を改修完了とはしていない。次は、現ショップに残る大きな空白と細い長文行を、今回の報酬・既存の休止／詳細画面と整合させる構成が有益な候補。製品報酬候補のfallback登録は見た目だけで決めず、既存の定義整備と区別する。攻撃本体モーション等の拒否済み素材や未決性能は本成果に含めない。物理タッチ／パッド、音の聴感、OS IMEの検証は行っていない。
