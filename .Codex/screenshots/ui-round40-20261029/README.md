## HPの範囲

- 全体仕様§3／§14と`ClearReturnSettings`の既定成長はLv1〜99、最大HP100〜590。変身では最大HPを変更せず、攻略中の成長反映も追加しない。
- `PlayerCharacter`／チェックポイントは正のint最大HPと0〜最大HPの現在値を扱う。これは登録済みの製品成長表とは別の、受入可能な数値域である。新しい製品HP値や上限・クランプを設定しない。
- 旧設定のHP欄360×48では、27文字の大値表示が16文字しか見えず、分母が欠けた。生成HP欄だけ標準BestFit（18〜28）を使い、値を省略せず同じ領域内へ収める。大値では2行になる。既存の明示割当欄の設定は変更しない。
- 既存の実Scene回帰へHP0、1／最大1、成長上限590、int最大値等を加え、Unity TextGeneratorの全字数表示を検証。通常単階層の進行度接続は新規回帰1件。既存期待値を緩めていない。
